# iOS: 우주 광장 별/성운 탭 합치기 (Figma 09-2, 420:16376)

- 요청: FIGMA 세션이 사용자 결정을 전달함 (2026-11-08).
- PlazaView
  - 세그먼트와 09 2열 StarShareCard 그리드를 지웠다.
  - 한 화면에 위에서부터 제목, 설명(새 문구), 오늘 밤 태그, 필터 줄, 성운 들판, 별 기록을 놓았다.
- PlazaFilter(새로 뜬 것 / 나와 결이 비슷한 / 곁에 둔 것)
  - 들판과 별 기록에 함께 적용한다.
  - 앞서 만든 「곁에 둔 별」 칩은 「곁에 둔 것」으로 합쳤다.
- PlazaNebulaField
  - 자체 필터 칩과 103 빈 상태를 빼고, 필터를 밖에서 받는다.
  - 비었을 때는 한 줄 안내를 보여 준다.
- PlazaStarRow
  - 44 썸네일에 ShapeStar(모양, 감정 색, 깊이 번짐)를 넣었다.
  - 문장은 Serif 15로 최대 2줄, 그 아래 "이름 · 상대 시각"을 둔다.
  - 오른쪽에 "✦ 공명 수"를 두고, 내가 공명했으면 보라색으로 칠한다. 행 사이에는 얇은 선을 둔다.
- "더 보기"는 20개씩 늘린다.
- 빈 상태
  - 새로 뜬 것·비슷한: "아직 나눠진 별이 없어요"
  - 곁에 둔 것: "곁에 둔 별이 아직 없어요" + 「새로 뜬 것 둘러보기」
- 목업 샘플은 Figma의 6행(시각, 공명 수)에 맞췄다.
- 라이브
  - 별 항목의 created_at과 resonance_count를 선택 필드로 읽는다. 없으면 시각은 숨기고 "✦"만 보여 준다.
  - 현재 서버는 둘 다 보내지 않는다. API 세션에 요청했다.
- 정책 확인 필요: 기존에는 "남의 공명 수는 라이브에서 보이지 않음"이었는데, 09-2는 수를 보여 준다.
- 확인
  - Debug 빌드 성공. -debugScreen 9 위쪽을 캡처했다.
  - 리스트는 임시로 위로 올려서 캡처한 뒤 원래대로 되돌렸다.

## 후속 (같은 작업)
- 공명 수
  - FIGMA 세션이 원칙을 다시 확인했다: 남의 공명 수는 보이지 않고, 주인에게만 보인다.
  - 별 기록 행은 ✦ 아이콘만 둔다. 공명했으면 보라색, 아니면 흐리게 보인다.
  - 선택 성운 카드는 깊이 태그만 두고, 내가 공명했을 때만 「공명했어요」를 붙인다.
  - resonanceCount 디코딩과 목업 수는 지웠다.
- 「곁에 둔 것」
  - 라이브에서는 서버 목록을 쓴다: GET /v1/plaza/stars?sort=beside, GET /v1/plaza/nebulae?filter=beside (곁에 둔 시각 최신순).
  - 목업은 공명 목록을 그대로 쓴다.
  - 공명 토글은 이제 별에도 PUT/DELETE /v1/plaza/star/{id}/beside를 함께 보낸다. 성운은 원래 그렇게 하고 있었다. 이렇게 해서 「공명 = 곁에 두기」 하나의 상태를 유지한다.
- created_at: 서버가 이미 보낸다(공유 시각). 라이브에서도 상대 시각이 보인다.
- 확인: Debug 빌드 성공. 리스트를 임시로 위로 올려 캡처한 뒤 원래대로 되돌리고 다시 빌드했다.
