# 모두의 은하(69)를 우주 광장에 합침 (2026-11-08)

- 요청: FIGMA DESIGN Session이 전달한 사용자 결정. 「모두의 은하」를 우주 광장에 합치고 이름도 「우주 광장」으로 바꾼다.

## 바꾼 것
- **08 나의 성운:** 보조 버튼 「모두의 은하」를 「우주 광장」으로 바꿨다. 그린 성운이 있을 때와 그리기 전 모두다. 누르면 화면을 쌓지 않고 우주 광장 탭으로 넘어간다.
- **우주 광장(09·72 공통):** 제목과 설명 아래, 세그먼트 위에 금색 태그 한 줄을 넣었다(69 "TONIGHT" 칩 스타일).
  - 문구는 "오늘 밤, {count}개의 마음이 모였어요 · 내 별 {mine}개도 함께 빛나요"다.
  - mine이 0이면 앞부분만, count가 0이면 줄을 숨긴다.
  - 데이터는 `/v1/plaza/tonight`의 count와 mine이다(`tonightMine` 추가). 광장 탭을 열 때 불러온다.
  - 목업은 Figma 69 견본 1,284와 내가 나눈 띄운 별 수다.
- **지운 것:** 69/76 화면(`GalaxyZoomView`), 그 들판(`GalaxyField`), 통계 칸(`GalaxyStat`), `galaxyZoom` route, 08 "모두의 은하" 링크
  - `-debugScreen 69/76`과 `-debugRoute galaxy`는 우주 광장 탭을 연다.
  - 앱 화면에 "모두의 은하" 문구는 남아 있지 않다.

## 확인
- 빌드 통과(Debug를 직접 지정)
- 캡처: 08(「우주 광장」 버튼), 09(오늘 밤 줄)

## 참고
- Xcode 공유 Scheme의 Run 설정이 Release로 바뀌어 있었다(사용자가 운영 서버 시험을 위해 바꾼 것으로 보인다).
  - 이 때문에 내 빌드가 Release로 만들어져 처음 캡처는 예전 Debug 앱이었다.
  - 이제 빌드 명령에 `-configuration Debug`를 직접 지정한다.
