# 글 수정 · 간직한 별 띄우기 · 띄우기 최소 50자 (2026-11-08)

- 요청: FIGMA DESIGN Session이 전달한 사용자 요청 세 가지. Figma 화면은 FIGMA 세션이 같은 기준으로 고친다.

## A. 띄우기 최소 50자
- `AppModel.minFloatLength` 1000 → 50
- 05·14 글자 수 안내: 50자 미만이면 "N자 · M자 더 쓰면 띄울 수 있어요", 이상이면 "N자"(기존 형식 그대로)
- "짧은 글은 '조용히 간직하기'로…" 안내는 50자 미만일 때만 보인다.

## B. 글 수정 (새 파일 `Screens/StarEditView.swift`)
- 별 상세(12)의 아래 줄에 "글 수정"을 넣었다(내보내기 · 글 수정 · 삭제).
- 05와 같은 편집 화면이다. 제목은 "글 수정"이고, 아래 버튼은 "저장" 하나다.
- **간직한 글:** 기분·제목·본문을 모두 고친다.
- **띄운 별:** 기분 칩은 잠그고 제목·본문만 고친다. 위에 "별의 모양과 리포트는 처음 띄운 글 그대로 남아요."를 띄운다.
- **저장:** 실제 API는 `PATCH /v1/stars/{id} {title, body, mood?}`(mood는 간직한 글일 때만), 목업은 기기 안에서 바꾼다.
  - API 세션이 추가할 예정이라 형식은 확인이 필요하다.

## C. 간직한 별 나중에 띄우기
- 간직한 별 상세에 주 버튼 "별 띄우기"를 넣었다. 오늘 무료를 썼으면 "별 띄우기 · 5코인"이다. "이 주제로 다시 쓰기"는 보조 버튼이 된다.
- 50자 미만이면 버튼을 끄고 "50자 이상이면 띄울 수 있어요"를 띄운다. 띄운 별에는 버튼이 없다.
- **흐름:** 누르면 별 쓰기 흐름(ComposeFlowView)을 쓰기 단계 없이 연다(`floatingKept`).
  - 비용은 새 글과 같다: 오늘 무료, 아니면 5코인. 모자라면 29 시트를 띄우고, "조용히 간직하기"를 고르면 그대로 닫힌다.
  - 실제 API는 `POST /v1/stars/{id}/float` 뒤 06 → 07, 402면 29 시트다.
  - 목업은 기기에서 분석을 붙여 06 → 07로 간다.

## 개발용
- `-debugRoute keptStar`(간직한 별 상세), `editStar`(띄운 별 수정), `editKept`(간직한 글 수정)

## 확인
- 빌드 통과
- 캡처
  - 간직한 별 상세: 샘플 본문이 비어 있어 "별 띄우기"가 꺼져 있고 50자 안내가 보인다.
  - 띄운 별 수정: 안내 배너가 보이고 기분 칩이 잠겨 있다.
  - 간직한 글 수정
  - 104: "11자 · 39자 더 쓰면 띄울 수 있어요"

## 확인하지 않은 것
- 50자 넘는 간직한 별을 실제로 띄우는 흐름과 수정 저장은 탭이 필요해 보지 못했다.
- 서버 PATCH는 API 세션 형식을 받은 뒤 확인한다.

## API 세션 형식 반영
- PATCH /v1/stars/{id} {title?, body?, mood?} → 200 {star, crisis, charged, coins}. 앱이 보내는 형식과 같다.
  - 응답의 star로 기기 사본을 바꾼다.
  - crisis가 있으면 수정 화면에서 37 위기 돌봄을 띄우고, "계속"을 누르면 닫는다. 목업은 기기의 위기 신호 검사를 쓴다.
  - 서버는 아직 커밋 전이다. 배포 전에는 운영에서 PATCH가 404/405로 실패하고, 앱은 공통 오류 토스트를 띄운다.
- POST /v1/stars/{id}/float
  - 위기 상태인 간직한 별은 점수 없이 kept로 돌아온다. 그러면 06 대신 37 → 13으로 간다.
  - 422 too_short, 409 already_floated는 서버 문구를 토스트로 띄우고 닫는다.
- 서버 최소 글자도 50자로 맞췄다("50자부터 별로 띄울 수 있어요.").

## FIGMA 검수 반영 (12-1)
- 간직한 별 상세의 보조 버튼을 "이 주제로 다시 쓰기" 대신 "글 수정"으로 바꿨다. 다시 쓰기는 리포트 질문을 잇는 흐름이라 분석이 없는 간직한 별에는 맞지 않다. 아래 줄은 "내보내기 · 삭제"다. 띄운 별은 그대로 "내보내기 · 글 수정 · 삭제"다.
- 샘플 간직한 별 "말하지 못한 이야기"에 50자가 넘는 본문을 넣었다(`StarItem.keptSampleBody`).
  - `-debugRoute keptStar`·`editKept`는 이 본문으로 연다.
  - 새 `-debugRoute keptShort`는 50자 미만 상태(버튼 꺼짐)로 연다.
