# 나의 성운(08)에 실제 성운 · 모양 바꾸기 (2026-11-08)

- 요청: FIGMA DESIGN Session이 전달한 사용자 요청
  - 08이 Figma 그림 좌표를 그대로 그려 누구에게나 같은 모양이 보였다.
  - 그린 성운의 모양을 바꿀 수 있어야 한다.
- 서버 형식은 API DEV Session이 보냈다(로컬 구현, 커밋·배포는 사용자 승인 대기).

## 08 나의 성운 (Figma 393:15253 / 393:15647)
- **08-1 (그린 성운이 있을 때)**
  - `updatedAt ?? createdAt`이 가장 최근인 성운(`latestNebula`)을 그린다.
  - 실루엣이면 기존 84 미리 보기 그림(`SilhouettePreview`)으로 그린다: 점선 틀, 기분 색 별, 금색 고리 손님별, 점선 빈 자리.
  - 직접 그리기면 고른 별과 선을 그린다(`StarStage`).
  - 캔버스 오른쪽 위에 「모양 바꾸기」 칩을 둔다.
  - 이름 줄은 "{성운 이름} · {실루엣 이름} · {단계}"이고, 직접 그리기면 실루엣 이름을 뺀다.
- **08-2 (그리기 전)**
  - 띄운 별을 기분 색으로 흩어 보여 주고, 아래에 "띄운 별 N개가 떠 있어요. 별을 골라 이으면 나만의 성운이 돼요."를 둔다.
  - 이름 줄은 "아직 이름 없는 성운 · {단계}"다.
  - 주 버튼은 「성운 그리기」이고, 링크 칩에서 성운 그리기를 뺀다.
- Figma 좌표를 그대로 그리던 `NebulaCanvas`는 지웠다.

## 모양 바꾸기 (84 → 52 → (53) → 85 → 54)
- 성운 그리기 흐름(`NebulaDrawingFlow`)에 `editing`을 더했다. 지금 실루엣·별·손님별·이름이 미리 채워진 채 84부터 시작한다.
  - 제목 "성운 모양 바꾸기", 헤더 "모양을 바꿀까요?", 버튼 "다음 · 별 다시 고르기"
  - 아래 두 줄: "우주 광장에 띄운 성운이면, 광장에서도 새 모양으로 바뀌어요." / "별을 바꾸면 다듬은 성운 이야기는 지워지고, 문장만 엮은 이야기로 돌아가요."
- 52에서 별을 다시 고른다.
  - 실루엣이면 "다음" → 85(빈 자리가 있을 때) → 54
  - 직접 그리기면 "이어 보기" → 53 → 54
- **저장**
  - 다듬은 이야기가 있고 별 목록이 바뀌었으면 "다듬은 이야기가 지워져요"(그대로 두기 / 바꾸기)를 묻는다. 실루엣이나 이름만 바꾸면 묻지 않는다.
  - 같은 성운을 그 자리에서 바꾸고(`updateDrawnNebula`, updatedAt) 08로 돌아온다.
- **서버:** `PATCH /v1/nebulae/{id}`
  - `silhouette`는 늘 보낸다. null이면 직접 그리기로 바뀐다.
  - `star_ids`는 `edges`와 함께 보낸다.
  - 응답의 `plaza_updated`가 true면 "광장의 성운도 새 모양으로 바뀌었어요" 토스트를 띄운다. 광장에 띄운 성운인데 false면(위기 신호 별) 광장에는 이전 모양이 남는다고 알린다.
- **불러오기:** GET /v1/nebulae의 updated_at이 기기 사본보다 새로우면 상세를 다시 받는다.
  - 별은 `index` 순서로 맞춘다(edges가 star_ids 순서 인덱스다).
  - 손님별은 guests[]의 name·share_id로 채운다.

## 개발용
- `-debugRoute nebulaDrawn`(08-1, 목업 등대 성운), `nebulaEmpty`(08-2), `reshapeNebula`(모양 바꾸기 84)
- Figma가 이 화면을 "84-1"이라 불러 계절 팩 84-1과 번호가 겹쳐서, 이름 route로 만들었다.

## 확인

- 08-1, 08-2(기분 색 별), 모양 바꾸기 84(지금 등대 선택, 안내 두 줄)를 캡처했다.

## 확인하지 않은 것
- 52 → 85 → 54 → 저장까지 탭 흐름, 다듬은 이야기 확인창, 서버 PATCH
- 서버 PATCH는 아직 배포 전이다. 그 전에는 운영에서 모양 바꾸기 저장이 기기에만 남고 오류 토스트가 뜬다.

## FIGMA 검수 · API 보완
- **08-1에 별이 안 보이던 문제:** 시뮬레이터에 남은 예전 목업 성운이 지금 없는 별을 가리켰다.
  - `-debugRoute nebulaDrawn / reshapeNebula`는 이제 매번 새 목업 성운을 만든다.
  - 띄운 별에 평온·슬픔·분노·통찰을 섞고, 손님별 2개를 넣었다.

  - 광장에서 내려간 기존 손님별은 서버가 조용히 뺀다. 앱은 다음 불러오기 때 guests[]를 따른다.
