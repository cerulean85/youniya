# 성운 모양 바꾸기 · 글 수정 서버 확인과 최소 별 3개 (2026-11-08)

- 계기: API 세션이 성운 다시 그리기를 운영에 배포했다(`6aae9e8`). 개발 서버에서 앱 형식 그대로 시험했다.
- 개발 서버 테스트 계정(ios-sim-test)은 비어 있었다. 동의, 별 3개(띄움 1, 간직 2), 시험 코인 110을 개발 서버에만 만들었다.

## 개발 서버 확인 (curl, 앱이 보내는 형식)
- **간직한 별 띄우기:** `POST /v1/stars/{id}/float`
  - 코인 0이면 402 insufficient_coins(cost 5)
  - 충전 뒤에는 floated, charged 5
  - 다시 띄우면 409 already_floated
- **글 수정:** `PATCH /v1/stars/{id}`
  - 띄운 별에 다른 mood를 보내면 409 mood_fixed. 앱은 띄운 별에 mood를 보내지 않는다.
  - 제목·본문만 보내면 200, updated_at이 찍히고 crisis는 없다.
- **성운 모양 바꾸기:** `PATCH /v1/nebulae/{id}`
  - 등대 → `silhouette: null` + edges로 직접 그리기가 됐다. 응답 stars[]의 index가 배열 순서와 달라서(0, 2, 1) 앱이 index로 정렬하는 것이 맞다.
  - 다시 고래로 바꾸면 이름과 실루엣이 바뀐다. GET /v1/nebulae mine[]에 updated_at이 온다.

## 앱 수정
- 서버가 성운의 별을 최소 3개(MIN_NEBULA_STARS) 요구한다. 앱은 직접 그리기 2개, 모양 바꾸기 1개만 골라도 넘어가서 거절될 수 있었다.
  - 51 시작: 띄운 별이 3개 미만이면 시작 버튼이 꺼지고 "별을 3개 이상 띄워 주세요"가 보인다.
  - 52 별 고르기: 3개 이상이어야 다음으로 간다. 안내는 "3개 이상 골라 주세요" / "N개 골랐어요 · 3개 이상이면 돼요"다.
- 54 성운 이름은 서버처럼 20자까지만 받는다.
