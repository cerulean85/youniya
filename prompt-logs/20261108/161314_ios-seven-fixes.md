# 사용자 요청 7가지 (2026-11-08)

- 요청: 사용자가 앱을 써 보고 고쳐 달라고 한 7가지. FIGMA DESIGN Session이 원인과 시안을 정리해 전달했다(Mobile y=27200 줄).

1. **로그아웃 확인 (87-5, 398:15600):** 설정 "로그아웃"이 바로 로그아웃하지 않고 시트를 띄운다.
   - 제목 "로그아웃할까요?", 본문 "쓴 글과 별은 그대로 남아 있어요. 다시 로그인하면 이어서 볼 수 있어요.", 버튼 로그아웃(주) / 취소
   - 서랍의 개발용 로그아웃은 그대로다.
2. **별 띄우기 전 안내 (05-3 398:15809 / 05-4 398:16001):** 05·14·간직한 별 띄우기에서 「별 띄우기」를 누르면 분석 전에 시트를 띄운다.
   - 무료일 때: "…나중에 글을 고쳐도 별의 모양은 그대로예요." + "오늘 무료 별 띄우기가 N번 남았어요." / 별 띄우기 · 조금 더 쓸게요
   - 코인일 때: "오늘 무료 별 띄우기를 다 썼어요. 코인 5개가 사용돼요(지금 N개)." / 코인 5개로 띄우기
   - 멤버는 오늘 남은 멤버십 횟수를 무료 문구로 보여 준다.
   - 코인이 모자라면 시트 대신 기존 29 코인 부족 흐름으로 간다.
   - 간직한 별 띄우기는 뒤에 빈 편집기를 보이지 않고, "조금 더 쓸게요"면 상세로 돌아간다.
3. **망원경이 안 켜짐**
   - 개발 서버에서 띄운 별의 리포트 만들기(POST /v1/telescope/reports)는 정상이었다. 앱 흐름에서 아무 반응 없이 끝나는 곳은 `openReport`의 "띄운 별이 아니면 끝냄" 하나였다.
   - 07이 띄우기 전 사본을 넘겨도 되도록 id로 모델의 최신 별을 다시 찾는다.
   - 그래도 띄운 별이 아니면 "아직 망원경을 켤 수 없어요" 토스트를 띄운다.
   - 실제 기기에서 재현하지는 못했다.
4. **별 상세에서 망원경 (12 / 12-2 398:16202):** 띄운 별 카드 아래에 보조 버튼을 둔다. 리포트가 없으면 "마음 망원경 켜기"(24/25), 있으면 "망원경 리포트 보기 ›"(10)다. 아래 줄은 내보내기 · 글 수정 · 삭제 그대로다.
5. **컬렉션 성운 카드**
   - 랜덤 별 6개 그림(`MiniShapeNebula`)을 지우고, 새 공용 렌더러(`DesignSystem/NebulaFigure.swift`)로 실제 성운을 작게 그린다.
   - 내 성운은 `NebulaArt`, 곁에 둔 성운은 광장 공유의 `shape`(silhouette, edges, stars의 mood)다. 목업은 이름으로 정한 고정 견본이다.
6. **장식 별 제거:** 08/70/77 캔버스 꼭대기의 금색 별을 뺐다. 실제 별, 손님별, 빈 자리, 선만 그린다. 다른 성운 화면에 같은 장식 이미지는 남아 있지 않다.
7. **광장 별 탭 카드**
   - 고정 이미지 두 장 대신 별 자체를 그린다(`StarShareCard`, 성운 카드와 분리).
   - 모양은 서버 `shape`({points, sharpness}), 색은 `mood`, 빛 번짐은 `depth_level`(1–5)로 정한다.
   - 서버의 광장 별·성운 항목에서 `shape`를 읽게 했다.

## 공용 렌더러
