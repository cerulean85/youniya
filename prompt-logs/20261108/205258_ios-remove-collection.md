  - CollectionScreens.swift(CollectionView)

- 디버그

- 광장 별 탭
  - 정렬 칩에 「곁에 둔 별」을 더했다. model.resonated에 든 광장 별을 새로 뜬 순으로 보여 준다.
  - 칩 줄은 FlowRow로 바꿔서 좁은 폭에서는 다음 줄로 넘어간다.
  - 비었을 때는 EmptyStateView("곁에 둔 별이 아직 없어요" + "새로 뜬 별 둘러보기")를 보여 준다. 성운 103과 같은 패턴이고, 문구는 Figma 확인이 필요하다.
- 확인
  - Debug 빌드 성공. 08은 칩 3개이고, 09는 정렬 칩 3개가 한 줄에 들어간다.
  - 「곁에 둔 별」 칩을 눌러 보는 확인은 하지 않았다(이번 세션에 시뮬레이터 조작 도구가 없음).
- CollectionScreens.swift 삭제는 다른 세션 커밋에 섞이지 않도록 스테이징하지 않고 작업 트리에만 둔다.
