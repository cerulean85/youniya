# 02-1 초대 계정 비밀번호 보기 (사용자 직접 요청, 2026-11-10)
- 요청: "초대 계정 입력할 때, 비밀번호에 무엇을 입력했는지 가려져서 확인을 할 수 없어."
- InviteLoginSheet 비밀번호 칸 오른쪽에 눈 아이콘(eye / eye.slash, 44pt 누름 영역). 누르면 TextField로 글자가 보이고 다시 누르면 가림. 보일 때 자동 대문자·자동 고침 끔. VoiceOver '비밀번호 보기/숨기기'.
- 시뮬레이터 02-1에서 시험 문자열로 보기·숨기기 확인. 커밋 안 함(빌드 17 심사 대기 중이라 다음 빌드에 포함).
- 참고: 같은 날 App Store Connect에서 1.0(17)+코인 3개 한 초안으로 묶고, 앱·코인 판매 나라를 대한민국만으로 바꿈(사용자 요청). 제출은 사용자가 직접 함 → 심사 대기 중.
