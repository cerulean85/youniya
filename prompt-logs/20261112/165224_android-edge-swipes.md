# 가장자리 쓸기 (뒤로 가기, 메뉴 열기)

## 요청
"왼쪽으로 쓸었을 때 이전 화면으로 안 돌아가고, 오른쪽으로 쓸었을 때 설정 화면이 안 나옴"

## 원인
- iOS는 DesignSystem/EdgeSwipe.swift에서 두 제스처를 직접 구현함.
  - 왼쪽 가장자리 20pt에서 오른쪽으로 끌기: 화면이 손가락을 따라오다, 너비 25% 또는 빠르게 튕기면 뒤로.
  - 오른쪽 가장자리에서 왼쪽으로 끌기: 메뉴가 손가락을 따라 열림(35%), 메뉴나 배경을 오른쪽으로 밀면 닫힘.
- Android에는 둘 다 없었음. 사용자 폰(갤럭시 S25)은 3버튼 방식이라 시스템 가장자리 제스처도 없음.

## 변경
- ui/components/EdgeSwipe.kt의 EdgeSwipeBack: 쌓인 화면마다 왼쪽 20dp 띠. 끄는 동안 바로 아래 화면(없으면 탭 화면)을 그림.
- MainScreen의 Drawer: Animatable로 바꿔 손가락을 따라 열고 닫음. 화면이 쌓여 있지 않을 때만 오른쪽 띠가 있음.
- 화면 분기를 page 람다로 꺼내, 아래 화면도 그릴 수 있게 함.

## 확인
- 에뮬레이터를 3버튼 방식으로 바꾸고 input motionevent로 끄는 중간과 놓은 뒤를 찍음.
  - 메뉴: 34% 끌다 놓으면 닫히고, 끝까지 끌면 열리고, 오른쪽으로 밀면 닫힘.
  - 뒤로: 별 상세와 설정 › 우주의 색(2단계)에서 아래 화면이 보이고 놓으면 돌아감.
- 에뮬레이터는 제스처 방식으로 되돌림. 갤럭시 S25에 설치.
- 제스처 방식 폰에서는 화면 가장자리를 시스템 뒤로 가기가 먼저 가져가므로, 그때는 시스템 뒤로 가기(슬라이드 애니메이션 포함)가 동작함.
