- 12 별 상세(별빛 받은 별): 아래 줄의 「글 수정」을 「고쳐 쓰기」로 바꿨다(내보내기 · 고쳐 쓰기 · 삭제).
- 05-2 (Route.revise)
  - StarMakingView revising 모드: 제목은 「고쳐 쓰기」, 안내 배너, 원래 글(기분, 제목, 본문)을 채워서 연다.
  - 버튼은 「새 별로 띄우기」 하나다.
  - 임시 저장은 model.reviseDrafts[원래 별 id]에 따로 둔다(메모리만). 새 별 임시 저장과 섞이지 않는다.
- 05-5 「고쳐 쓴 글을 새 별로 띄울까요?」
  - 본문은 원래 별 이름, 이어진다는 안내, 비용(무료 몫 또는 코인, 별빛 없이는 무료와 남은 횟수)이다.
  - 버튼은 「별빛 받고 새 별로 띄우기 / 별빛 없이 새 별로 띄우기 / 조금 더 고칠게요」다.
  - 50자 미만에서 별빛을 고르면 토스트를 띄운다. 코인이 부족하면 29-1로 간다.
- 새 별로 띄우기
  - 목업: publishRevision이 rewriteOf를 둔다.
  - 라이브: POST /v1/stars에 rewrite_of를 보낸다(서버가 두 별을 자동으로 잇는다).
  - 35 다시 시도나 29-1 「별빛 없이」로 다시 보낼 때도 연결을 유지한다.
  - 실패해서 에디터로 돌아오면 고쳐 쓴 글을 다시 저장한다.
  - 별빛을 받으면 06 → 61 → 07-1로 가고, 별빛 없이 띄우면 61 → 12-1과 토스트로 간다. 16 비교 화면은 쓰지 않는다.
- 12-10 / floatKept 경로: replace 대신 push로 바꿨다. 「다음에」를 누르면 별 상세로 돌아온다.
