# iOS 5단계 5A: 별지기 이름 (기획 15장, Figma 21-1 427:17026, 21-2 427:17170, 87-6 427:17459, 87-7 427:17315)

- 요청: 사용자가 "커밋하고 5단계 진행해줘"라고 했다. 4단계는 6f9db5e로 커밋했다.
- 모델
  - AppModel.nickname과 nicknameNextChange를 UserDefaults에 둔다. /v1/me의 nickname과 nickname_next_change를 읽는다.
  - 계정을 삭제하면 둘 다 비운다.
  - justConsented: 가입 동의 직후에만 21-1을 띄우려는 표시다.
- App/Nickname.swift
  - 형식 검사: 2~12자, 한글·영문·숫자, 예약어
  - checkNickname: GET /v1/me/nickname/check. 목업은 「고요한새벽」만 이미 쓰는 이름으로 본다.
  - setNickname: PUT /v1/me/nickname. 429 nickname_too_soon과 409 nickname_taken은 문구로 바꿔 보여 준다.
- NicknameView
  - 모드: signup(가입 직후), plaza(예전 가입자가 광장에 들어갈 때), change(87-7)
  - 입력을 멈추고 0.4초 뒤에 이름을 확인한다. 「✓ 쓸 수 있는 이름이에요 · N/12」(초록) 또는 21-2 문구(빨강)가 뜬다.
  - 30일이 지나지 않았으면 「다음 변경은 M월 d일부터 할 수 있어요」를 보여 주고 버튼을 끈다.
- YouniyaApp: 가입 동의 → 별지기 이름(21-1) → 메인
- 87 설정: 맨 위에 「계정 · 별지기 이름 ›」을 두고 87-7로 간다. 이름이 없으면 정하기로 간다.
- 새 디버그 화면: 21-1, 21-2, 87-6, 87-7
- 확인: Debug 빌드 성공. 21-1, 87-7, 87-6을 캡처했다.
- 남은 것
  - 광장에 들어갈 때 이름이 없으면 막는 처리는 5B에서 한다.
  - 「내 별지기 페이지 미리 보기」는 5B(76-1)에서 한다.
  - 87의 소리 줄 삭제는 6단계에서 한다.
