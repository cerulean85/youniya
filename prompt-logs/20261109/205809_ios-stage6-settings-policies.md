# iOS 6단계: 설정, 약관, 멤버십 안내 정리, 망원경 응답 맞춤

- 요청: 사용자가 "커밋하고 6단계 진행해줘"라고 했다. 5단계는 fea6cf9로 커밋했다.
- 87 설정 (Figma 87-6)
  - 소리 줄(앰비언스 사운드, 소리 고르기)과 94 시트를 지웠다(기획 9.3·11.6: 2026-11-08에 뺐다).
  - 「새 기능·혜택 알림」을 켜고 끄면 서버에 저장한다: setMarketing → PUT /v1/me/marketing {opt_in}. 실패하면 되돌린다. 결과는 서버가 consent_result 푸시로 알려 준다(배너만 띄우고 따로 여는 화면은 없다).
  - 92 「모든 공유 거두기」 문구는 별만 센다(성운 공유가 없어졌다).
- 약관: 44 개인정보 처리방침(1~9), 46 결제·환불 정책(1~8), 31 새 기능·혜택 알림 수신 동의(6항목)를 Figma 18:872 / 18:931 / 299:13784 전문으로 바꿨다. 43과 45는 앞서 바꿨다.
- M1 혜택: 「별빛 받기 하루 10번 · 마음 망원경 하루 10번 · 띄운 별마다 · 우주의 색 장면 3가지 · 앱 아이콘」(계절 팩과 월간 리포트를 뺐다)
- 정리: MonthlyReport, MonthlyReportItem, MonthlyOut, MonthlyList, loadMonthlyReports, monthlyReport, monthlyReports, 디버그 94를 지웠다.
- API 5단계 운영 배포에 맞춘 망원경 결과
  - fog_items는 {kind(키), label(이름), sentence, note}다. 앱은 label을 보여 준다.
  - mood_flow는 {start, middle, end}이고 값은 감정 하나씩이다. 앱은 「글의 시작 / 중간 / 끝」 줄로 바꾼다. 줄마다 풀이가 없으면 풀이를 숨긴다.
  - 이전 디코딩은 배열을 기대해서, 새 서버 응답을 받으면 결과 전체를 읽지 못했을 것이다.
  - prism_version 「prism-v1-2026-11」은 「별빛 프리즘 v1」로 보여 준다. 예전 별은 값이 없어서 풀이 줄을 숨긴다.
- 확인: Debug 빌드 성공. 87, 44, M1을 캡처했다.
- 남은 정리: 쓰지 않는 성운 모델과 API(DrawnNebula, GalaxyNebula, 하늘에 띄우기 / 손님 후보 API, nebulaLines 등). 화면은 모두 지웠지만 모델이 얽혀 있어 따로 정리한다.
