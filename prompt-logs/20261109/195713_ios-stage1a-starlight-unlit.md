# iOS 1단계 1A: 별빛 받기 / 별빛 없이 띄우기 (기획서 17장, Figma 05·104·05-3·05-4·29-1·12-1·118·119)

- 요청: 사용자가 "1단계부터 진행해줘"라고 했다. 서버 이름은 API 세션 답을 따랐다.
  - mode lit/unlit (float/keep 별칭), moods[], has_starlight/locked, POST /stars/{id}/starlight, 429 unlit_daily_limit, 409 star_locked
  - 1단계 서버는 아직 배포되지 않았다. 그래서 앱은 지금 mode를 float/keep로 보내고, moods[]는 함께 보낸다(옛 서버는 무시한다).
- 05 별 만들기
  - 기분을 여러 개 고를 수 있다(StarDraft.extraMoods, toggle). 처음 고른 기분이 별 색이고, 최소 1개는 남는다.
  - 기분 칩 아래에 안내 문구를 넣었다.
  - 버튼은 「별빛 없이 띄우기 | 별빛 받고 띄우기」다.
  - 104 문구를 「별빛을 받을 수 있어요」로 바꿨다.
- 05-3 / 05-4 「별빛을 받아 띄울까요?」
  - 잠김을 안내한다. 버튼은 「별빛 받고 띄우기 · 오늘 무료 1번 / · 5코인」, 그 아래 「조금 더 쓸게요」(ghost)다.
  - 12-1에서 열 때는 「별빛 받기」 문구를 쓴다.
- 29-1 코인 부족: 충전 / 별빛 없이 띄우기 / 계속 쓰기
- 별빛 없이 띄우기
  - 13 완료 화면 대신 61 탄생 연출 뒤 12-1 별 상세로 간다.
  - 하루 10개 한도: 목업은 직접 세고, 라이브는 429 unlit_daily_limit을 받으면 토스트를 띄운다.
- 12-1
  - 날짜 줄에 「· 별빛 없는 별」을 붙였다.
  - 「별빛 받기」(primary)와 가격 안내, 「글 수정」을 둔다.
  - 「조용히 간직한 별이에요」 문구는 지웠다.
- 글 잠금
  - 별빛 받은 별의 글 수정은 제목만 바꾼다. 본문은 읽기 전용이고 안내 배너를 둔다.
  - editStar는 body를 nil로 보낸다.
- 문구: 간직한 별 → 별빛 없는 별(기록 칩, 118/119, 서랍, 별 행, 내보내기, 멤버십 안내, 성장 순간)
- 새 기획에서 빠진 손님별 바로 들이기를 지웠다(75 버튼, adoptGuest, include_guests).
- 새 디버그 화면: 12-1
