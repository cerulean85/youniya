- 06 (495:28064)
  - 글 위를 어둡게 덮고 궤도 로더를 둔다. 점선 고리 셋(cyan / pink / violet)과 각자의 점이 서로 다른 속도로 돈다. 가운데는 보라 4각 별이다.
  - 제목과 설명 아래 단계 칩 셋: 별의 깊이 → 빛의 선명함 → 마음의 무게. 1.3초마다 하나씩 체크된다.
  - 라이브(.reading)는 서버 답이 올 때까지 단계 칩이 계속 돈다.
  - 예전 프리즘 빔 연출(PrismStage)과 축 측정 막대, 암호화 안내는 지웠다.
- 별빛 풀이 (17.3)
  - StarAnalysis에 depthReason, clarityReason, weightReason, interpretation, prismVersion을 더했다. 서버의 depth_reason 등과 별 최상위 prism_version을 읽는다.
  - 점수는 깊이 ×400, 선명함 ×300, 무게 ×300으로 계산한다.
  - 목업과 샘플은 Figma 07-1 문구를 쓴다(318 + 176 + 248 = 742).
- StarlightBreakdown (Components 새 파일)
  - 「별빛 N는/은 이렇게 모였어요」, 세 줄(점수, 막대, 이유), 종합 해석, 안내 문구, 「… · 2026년 11월 방식으로 읽었어요」
  - 값이 없는 부분은 숨긴다.
  - BreakdownToggle은 「별빛 풀이 보기 ▾ / 접기 ▴」다.
  - appear()는 0.5초 동안 12pt 올라오며 밝아진다. 동작 줄이기가 켜져 있으면 바로 보인다.
- 07-1 StarCardView
  - 순서: 카드 → 풀이(펼침) → 토글 → 망원경 맛보기 → 「나의 별자리 보기」 / 「마음 망원경 켜기」
  - 묶음은 0.2초 간격, 풀이 안의 줄은 0.18초 간격으로 나타난다.
  - 카드를 눌러도 풀이를 접고 편다.
