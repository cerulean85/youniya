# iOS 2단계 2B: 별자리 자세히 보기 (Figma 70 32:5507, 77, 77-2 457:15177)

- 요청: 2단계를 이어서 진행했다.
- ConstellationDetailView (Route.constellation("YYYY-MM"))
  - 맨 위는 금빛 태그 「11월 · 채우는 중 6 / 9」(다 채우면 「완성」)와 별자리 이름(h1)이다.
  - 큰 별자리 그림: 두 손가락이나 + − 로 확대한다(1–2.6×).
  - 별을 누르면 점선 고리가 생기고, 정보 표 자리에 「내 별 · 제목」 카드와 「별 보기 ›」가 온다(77-2). 다시 누르면 해제된다.
  - 정보 표(70): 채운 자리 / 평균 깊이(별빛 받은 별의 깊이 × 5단계) / 빛깔 / 가장 밝은 별
  - 그 아래 칩 「별자리 이야기」, 맨 아래 「이미지로 저장」이 있다(그림을 렌더해 사진첩에 저장하고 토스트를 띄운다).
- 08-3의 「자세히 보기」와 「남은 자리」는 보고 있는 달의 상세를 연다.
- 디버그: 70 / 77 / 77-2는 이번 달 상세를 연다. 71 / 112는 아직 예전 성운 화면이다(2C에서 정리한다).
- 확인: Debug 빌드 성공. 70을 캡처해서 Figma와 맞는지 봤다. 확대와 별 고르기는 눌러 보지 못했다.
- 남은 것
  - 77-2의 은빛 점선(같은 달의 이어진 별)은 3단계 별 잇기 데이터가 들어온 뒤에 넣는다.
