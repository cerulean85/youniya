# iOS 3단계: 별 잇기 (기획 11.5, Figma 12-2·12-6·12-7·12-9·14·77-2)

- 요청: 사용자가 "커밋하고 3단계 진행해줘"라고 했다. 2단계는 e140f58로 커밋했다.
- 데이터
  - StarItem.linkedIDs: 방향 없이 양쪽에 둔다.
  - 라이브 별 상세의 linked_stars를 읽는다.
  - App/StarLinks.swift
    - linkedStars
    - linkLocally
    - linkStars: POST /v1/stars/{id}/links {star_ids}
    - unlinkStars: DELETE …/links/{other}
  - 고쳐 쓰기(05-2)와 14로 만든 새 별은 목업에서도 원래 별과 이어진다.
  - 라이브 14는 POST /v1/stars에 link_to를 보낸다(05-2는 rewrite_of).
- 12 별 상세
  - 주 버튼 「이 주제로 다시 쓰기」를 「별 잇기」로 바꿨다.
  - 「이어진 별 N」 묶음: 기분 색 점 · 제목 · 날짜 칩. 누르면 그 별로 가고, 길게 누르면 「연결 끊기」가 나온다.
- 12-6 「이 별과 무엇을 이을까요?」: 새 글을 써서 잇기(→ 14) / 이미 쓴 별과 잇기(→ 12-7) / 취소
- 12-7 LinkStarsView
  - 위에서부터 제목, 안내, 검색, 필터 칩(전체 / 띄운 별 / 별빛 없는 별 / 기분)
  - 별을 달별로 묶어 보여 준다. 자기 자신과 이미 이은 별은 뺀다.
  - 오른쪽 원을 누르면 바로 골라지고, 아래에 「N개 별 잇기」가 뜬다. 성공하면 토스트를 띄운다.
- 12-9: 행을 누르면 미리 보기 시트(날짜, 별빛 여부, 제목, 본문 전체, 이미 이어진 별)가 뜬다. 버튼은 「이 별 고르기」 / 닫기다.
- 14 RewriteView
  - 제목을 「별 잇기 · 새 별 쓰기」로, 카드 머리를 「이어 쓰는 글 · 제목」으로 바꿨다.
  - 버튼 문구도 별빛 용어로 바꿨다.
  - 16 비교 화면으로 가지 않고 07-1로 간다.
- 77-2
  - 고른 별과 같은 달의 이어진 별을 은빛 점선으로 잇는다.
  - 카드에 「이어진 별 N · 이번 달 M개는 은빛 선으로 보여요 · 다른 달 K개」를 보여 준다.
- 디버그
  - 새 화면: 12-6, 12-7(12-9)
  - 12-2 / 12-6 / 12-7 / 77-2는 샘플 별을 다른 별 두 개와 이어 둔다.
- 확인
  - Debug 빌드 성공.
  - 12-6, 12-7, 14, 77-2를 캡처했다.
  - 고르기, 잇기, 끊기는 눌러 보지 못했다.
- 남은 것
  - 12-8 달력으로 고르기
  - 81 은하수의 달을 넘는 은빛 점선(GET /v1/constellations의 cross_links)
  - 14 화면: 키보드가 올라오면 편집 칸이 질문 카드 위로 겹쳐 보인다. 예전부터 있던 배치 문제로, 따로 고쳐야 한다.

## 후속: 남은 세 가지 (사용자가 "남은 세가지 마저 하고, 커밋"이라고 했다)
- 12-8 달력 (455:15104)
  - 12-7에 「목록 | 달력」 세그먼트를 더했다.
  - 달력: ‹ 연월 ›(이번 달 다음으로는 못 넘긴다), 요일 줄, 날짜 칸. 별이 있는 날에는 ✦를 두고, 고른 별이 있는 날에는 보라 원을 두른다.
  - 날짜를 누르면 그날의 별 행이 나온다. 행은 목록과 같아서 고르기와 12-9 미리 보기가 그대로 된다.
  - 새 디버그 화면: 12-8
- 81 은하수
  - 서로 다른 달의 별 사이 별 잇기를 은하수 위의 은빛 점선 호로 그린다.
  - 데이터는 기기의 linkedIDs다. 라이브는 별 상세의 linked_stars에서 채워진다.
  - 디버그 81은 11월 별과 10월 별을 이어 둔다.
- 14 배치
  - 편집 칸 높이를 고정 260에서 최소 120, 최대 260으로 바꾸고, 다른 요소보다 먼저 줄어들게 했다(layoutPriority -1).
  - 이제 키보드가 올라와도 질문 카드와 겹치지 않는다(14와 105 캡처로 확인).
