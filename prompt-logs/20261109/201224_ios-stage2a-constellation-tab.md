# iOS 2단계 2A: 나의 별자리 탭(08-3)과 04 이번 달 별자리 카드

- 요청: 사용자가 "커밋하고 2단계 진행해줘"라고 했다. 1단계는 dfad75d로 커밋했다.
- App/Constellation.swift
  - ConstellationTemplate.byMonth: Figma 501:13915에서 읽은 12개월 자리 좌표(342×300 비율)와 선
  - MonthConstellation: 자리마다 별, 금빛 선 판단, 남는 별(extra), 깊은 별
  - 목업: 이 기기의 별을 그달 날짜 순으로 채운다. 깊은 별은 별빛 받은 별 중 깊이 280 이상이다.
  - 라이브: GET /v1/constellations/{YYYY-MM}의 slots, lines, extra, deep을 liveConstellations에 둔다. 404(가입 전이나 미래 달)는 무시한다.
- ConstellationFigureView
  - 양쪽이 채워진 선은 금빛, 나머지 선은 흐린 점선이다.
  - 채운 자리는 기분 색 별이다. 별빛 받은 별은 별빛에 따라 크고 빛나고, 별빛 없는 별은 작고 흐리다.
  - 빈 자리는 점선 원이고, 남는 별은 둘레에 흐리게 뜬다.
- 08-3 ConstellationView
  - 위에서부터 제목, 「11월 · 페가수스자리 · 별 N개」, 캔버스(달 이름, ‹ ›와 스와이프, N / M)
  - 통계: 떠 있는 별 / 깊은 별 / 남은 자리
  - 안내 문구는 진행 중 / 완성 / 지난달 세 가지다.
  - 버튼은 「우주 광장 | 자세히 보기」, 칩은 「별자리 이야기 · 나의 은하수」다.
  - 지난달로 넘길 때는 첫 별이 있는 달까지만 가고, 이번 달 다음으로는 못 넘긴다.
- 04 HomeView: HeroConstellation을 MonthConstellationCard로 바꿨다(그림, 자리 채움 막대, 「별자리 보기 ›」 → 별자리 탭).
- 탭바 라벨: 성운 → 별자리
- 「자세히 보기」와 「남은 자리」는 임시로 기존 77로 간다(2B에서 바꾼다). 별자리 이야기는 기존 83으로 간다(2C).
- 확인
  - Debug 빌드 성공.
  - 08-3과 04를 캡처했다(11월 페가수스자리 3/9).
  - 탭과 스와이프는 눌러 보지 못했다.
