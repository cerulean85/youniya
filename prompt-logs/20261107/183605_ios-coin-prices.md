# 코인 가격과 무료 횟수 (2026-11-07)

- 요청: FIGMA DESIGN Session이 전달한 사용자 확정 가격(코인 1개 = 10원). 서버 형식은 API 세션이 알려 줄 예정이다.

## 가격과 무료
- **별 띄우기:** 하루 1개 무료, 같은 날 두 번째부터 5코인. 조용히 간직하기는 항상 무료.
  - `AppModel.floatCost = 5`. 오늘 띄운 별 수(`floatedToday`)로 무료인지 정한다.
  - 05·14의 버튼은 무료를 썼으면 "별 띄우기 · 5코인"이 된다.
  - 코인이 모자라면 29 시트("코인이 조금 부족해요")를 띄운다. 버튼은 코인 충전 / 조용히 간직하기 / 계속 쓰기다. "코인 충전"은 28로 간다.
  - 목업은 앱이 5코인을 쓰고 내역에 "별 띄우기"를 남긴다. 실제 API는 서버가 받고, 402가 오면 같은 29 시트를 띄운다.
- **마음 망원경:** 20코인. 가입 첫 1회 + 매달 1회 무료.
  - 목업은 이번 달 무료를 쓴 달(`monthlyFreeTelescopeMonth`)을 기억한다.
  - 07 배지 "이번 달 1회 무료"는 무료가 남아 있을 때만 보인다.
  - 24는 무료면 "무료로 켜기"(본문 "이번에는 무료로 켤 수 있어요."), 아니면 "코인 20개로 켜기"다.
  - 목업에서 무료를 쓸 때 코인이 빠지던 문제도 고쳤다.
- **서사 다듬기(83):** 10코인. 가입 첫 1회 무료면 "서사 다듬기 · 첫 1회 무료"(`usedFreePolish`)
- **충전 상품(28, 28-1):** coin_110 ₩1,100 / coin_330 ₩3,300 / coin_1100 ₩9,900 · 보너스 100 포함. 예전 coin_50/120/300은 뺐다.
- **문구**
  - 03·03-1: "별 띄우기는 하루 한 번 무료예요"
  - 43 제4조: 새 문구
  - 108: "마음 망원경 등에 쓴 코인이 / 여기에 차례로 쌓여요."
  - 121 목업 환불: −330
  - 102는 충전한 코인 수를 그대로 보여 준다.

## 서버 연결 (API 세션 `e24a01d`)
- `/v1/me`와 `/v1/coins`의 `free_star_today`(0/1), `free_telescope`(0–2), `free_story`(0/1)를 읽는다(`applyFreeUses`).
  - 오늘 무료 별 띄우기, 망원경 무료(이번 달 + 가입 1회), 첫 서사 다듬기 무료를 서버 값으로 정한다.
  - 목업은 기기 계산을 그대로 쓴다.
- 실제 API로 별을 띄우면 잔액과 무료 횟수를 다시 불러온다(서버가 5코인을 받았을 수 있다).
- 402 insufficient_coins는 저장 전에 오므로, 05 초안을 그대로 두고 29 시트를 띄운다.
- 개발 서버 확인(curl, ios-sim-test)
  - /v1/me와 /v1/coins에 세 필드(1, 1, 1)가 온다.
  - /v1/coins packages는 coin_110, coin_330, coin_1100이고 prices는 star 5, telescope 20, story 10이다.
- App Store Connect에 새 상품(coin_110, coin_330, coin_1100)을 등록해야 실제 결제가 된다. 예전 상품은 서버가 구매·환불 처리를 계속 받는다.
