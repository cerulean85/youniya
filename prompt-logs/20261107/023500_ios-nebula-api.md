  - 손님별(85)은 지금 기기 샘플이라 보내지 않는다. TODO: `GET /v1/nebulae/guest-candidates`(공명한 광장 별)

  - 저장 직후에 누르면 서버 저장이 끝나기를 기다렸다가 보낸다(`nebulaCreates`).
  - 71 "가린 한 문장 함께 보이기"를 켜면, 성운의 별 본문에서 300자 이하인 가장 긴 문장을 보낸다. 서버가 다시 가린다. TODO: 사용자가 고르기
  - 71은 가장 최근에 그린 성운을 띄운다. 실제 API에서 그린 성운이 없으면 "먼저 성운을 그려 주세요" 안내를 띄운다.
