# 멤버십 한도 하루 10개 (2026-11-07)

- 요청: FIGMA DESIGN Session이 전달한 사용자 결정("무제한"이라는 말은 쓰지 않는다)
- **한도:** 멤버는 별 띄우기·마음 망원경·서사 다듬기를 각각 하루 10번까지 쓴다. 넘으면 코인으로 쓴다.
- **M1 혜택 문구:** "별 띄우기 하루 10개" / "마음 망원경 하루 10번 · 띄운 별마다" / "서사 다듬기 하루 10번" / "월간 마음 리포트" / "우주의 색 장면 3가지 · 아이콘 · 성운 실루엣 계절 팩"
- **28-2 카드:** "별 띄우기·마음 망원경 하루 10번"
- **판단**
  - 남은 횟수는 GET /v1/membership의 `stars_left_today`, `telescope_left_today`, `story_left_today`를 쓴다(`memberLeftToday`). 이름은 FIGMA 세션이 전한 것이고, API 세션의 형식이 오면 맞춰 본다.
  - 목업은 오늘 띄운 별 수로 남은 별 띄우기를 센다.
  - 남은 횟수가 0이면 05 "별 띄우기 · 5코인", 24 코인 문구, 83 "코인 10"으로 돌아간다.
  - 잔액을 다시 불러올 때(별 띄우기·다듬기 뒤 포함) 멤버십 남은 횟수도 다시 불러온다.

## API 세션 형식 (`aff5ffb`)
- `stars_left_today`, `telescope_left_today`, `story_left_today`(각 0–10, 한국 날짜)가 앱이 읽는 이름과 같다. 없어진 `telescope_left_this_month`는 앱에서도 뺐다.
- /v1/me의 free_star_today·free_telescope·free_story는 이제 멤버 횟수와 무료 횟수를 더한 값이다(예: 11/12/11). 앱은 0보다 큰지만 보므로 그대로 맞다.
- 월간 리포트는 다시 만들 수 없다. 앱에는 다시 만들기 버튼이 없다.
