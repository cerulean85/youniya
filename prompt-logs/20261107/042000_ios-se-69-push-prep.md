# SE 69 맞춤, 시험 알림 준비 (2026-11-07)

- 요청: "진행해줘" (남은 일 진행). 진행 중에 FIGMA DESIGN Session이 "Mobile · SE (375×667)" 페이지와 SE 69 지적을 보냈다.

## 시험 알림 준비
- 새 번들 ID 앱은 알림 권한을 받은 적이 없어 기기 토큰이 서버에 없다.
- 개발용 `-requestNotifications YES`: 실행하자마자 알림 권한을 묻는다. 허용되면 토큰이 `/v1/me/devices`로 등록된다.
- 확인용 시뮬레이터(iOS Session Check)에 ios-sim-test 계정(`f8f2ba3a-25ef-426d-a620-61e6453ed631`)으로 띄워 권한 창까지 열었다. "허용"은 사용자가 Simulator에서 눌러야 한다.

## 공개할 문장 고르기 (19·71)
- 시안이 필요해서 FIGMA DESIGN Session에 요청했다. 그쪽이 사용자에게 흐름을 확인한 뒤 그린다.

## SE 69 (Figma "Mobile · SE" 기준)
- 높이가 낮은 화면(전체 화면 700pt 미만)에서
  - 제목을 26pt 두 줄로 줄인다.
  - 은하 캔버스를 210pt로 줄인다.
  - 구역 간격을 16에서 8로 줄인다.
- 높이는 전체 화면 배경에서 잰다. 내용 높이로 재면 넘친 내용 때문에 SE로 인식하지 못했다.
- SE에서 제목 두 줄, 캔버스, 안내 문구, 통계 카드, 버튼이 겹치지 않고 모두 보인다.
