# -debugScreen: Figma 화면 번호로 바로 열기 (2026-11-07)

- 요청: FIGMA DESIGN Session(사용자가 나머지 화면 전체 시각 검수를 요청). 이 Mac에서는 시뮬레이터를 탭할 수 없어서, Figma 프레임 번호로 화면을 바로 여는 실행 인자가 필요하다.

## 사용법 (Debug 빌드만)
- `xcrun simctl launch <기기> com.dycdyp.youniya -debugScreen 07`
- 번호는 Figma Mobile 프레임 번호다. 07과 7은 같다. 28-1, 67-1, 122-1처럼 붙임표도 된다.
- 항상 목업 모드로 연다. 로그인, 동의, 스토리·광장 안내 본 상태를 화면에 맞게 정하고, 별이 모자라면 샘플 별을 채운다.

## 구조
- `App/DebugScreen.swift`
  - `DebugScreen.current`, `DebugScreen.is(...)`
  - `supported` 목록
  - `prepare(model)`: 앱 전체 상태를 정한다(로그인·동의, 39·40·41·113·120 알림, 스켈레톤 47~50·110~112, 98·108·109·119 빈 상태, 101·107·121 샘플 등).
- `MainView.openDebugScreen()`: 탭과 페이지를 고른다.
- 시트나 화면 안 단계는 각 화면의 초기 상태에 한 줄씩 넣었다.
  - 15·19 별 상세 시트, 24·29 망원경, 27 정렬, 28-1·38·102 충전
  - 34 나가기 시트, 71 띄우기 시트, 72 광장 성운
  - 80·96·97 컬렉션, 116·117 기록
  - 91~95·114 설정 시트, 99·100·106 별빛 한 줄, 105 다시 쓰기
  - 06·07·13·16·35·36·37·61·62 쓰기 흐름 단계
- RootView: 01은 스플래시에 머문다.

## 열 수 없는 번호

- 57~60: 스토리 뒤쪽 페이지(56만)
