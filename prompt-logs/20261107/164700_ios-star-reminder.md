# 별 만들기 알림 (87-1, 87-2) · 기기 푸시 시험 (2026-11-07)

- 요청: "다음 할 일 진행해줘"
- 사용자 결정
  - 별을 띄우지 않은 날에만 보낸다. 시각은 사용자가 고른다.
  - 문구는 "조용한 초대"로 한다.

## Figma 시안 (먼저 만듦)
- **87-1 설정 · 별 만들기 알림 켬 (329:40600):** 87을 복사해 만들었다.
  - "별 만들기 알림"을 켰다.
  - 그 아래에 Settings Row(Value) "알림 시각 · 오후 9:30"을 넣었다(Icon/moon).
  - 안내를 "별을 띄우지 않은 날에만 고른 시각에 한 번 알려 드려요. 연속 기록이나 재촉하는 알림은 보내지 않아요."로 바꿨다.
  - 원래 87은 알림 섹션 높이가 고정이라 안내 글이 다음 행에 겹쳐 있었다. 87-1에서는 섹션 높이를 내용에 맞췄다. 원래 87은 그대로 두었다.
- **87-2 설정 · 알림 시각 고르기 (329:42606):** 87-1 위에 94 시트 구성을 쓴 시트다.
  - 제목 "언제 알려 드릴까요?", 본문 "별을 띄우지 않은 날에만, 이 시각에 한 번 조용히 알려 드려요."
  - 오전/오후·시·분 휠(5분 단위)
  - 버튼 "저장"·"취소"

## 앱 (새 파일 `App/StarReminder.swift`)
- `AppSettings.reminderMinutes`: 기본 21:30(오후 9:30). 예전 저장값도 읽힌다.
- **알림 내용:** 기기 안의 로컬 알림. 제목 "오늘 밤하늘", 본문 "오늘 마음에 남은 장면이 있다면, 별로 띄워 볼까요?"
- **"별을 안 띄운 날만" 처리**
  - 로컬 알림은 울릴 때 조건을 확인할 수 없다. 그래서 앞으로 14일을 하루씩 따로 예약하고, 오늘 별을 쓰면 오늘 것을 뺀다.
  - 띄운 별뿐 아니라 조용히 간직한 별도 쓴 것으로 센다.
- **다시 예약하는 때**
  - 알림을 켜거나 끌 때, 시각을 바꿀 때
  - 별 목록이 바뀔 때
  - 앱으로 돌아올 때(14일을 다시 채우고, iOS에서 알림을 끈 경우를 따른다)
- **87:** "별 만들기 알림"을 켜면 "알림 시각" 행이 나타나고, 누르면 87-2 시트가 열린다.
  - 시트의 휠은 UIKit `UIDatePicker`다. SwiftUI DatePicker는 5분 단위를 지원하지 않아서다.
  - 섹션 안내 문구는 알림이 켜졌을 때 87-1 문구로 바뀐다.
- 개발용: `-debugScreen 87-1`, `-debugScreen 87-2`

## 기기 푸시 시험 (API DEV Session)
- 16:45:50 iPhone(Google 계정)이 `PUT /v1/me/devices`로 sandbox 토큰을 등록했다(204).
- API 세션이 시험 푸시("시험 알림")를 보냈고 APNs가 200으로 받았다.
- 예전에 등록된 토큰 8036cc44…는 번들 ID를 바꾸기 전 것이라 APNs가 DeviceTokenNotForTopic으로 거절했다. 서버가 자동으로 지웠다.
- 앱은 열려 있을 때도 배너를 띄운다(`willPresent` → banner, sound, list).
