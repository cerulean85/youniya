# iOS 앱 결제·환불 정책: 코인 1년 미이용 소멸 (App Store 예외) — 2026-11-19
- 요청: 토스페이먼츠 등록 준비 세션이 전한 사용자 결정(1년 미이용 소멸, 양도 불가, 7일 환불, 시행 12-01). App Store 심사 지침 3.1.1(인앱 결제 크레딧 만료 불가) 때문에 사용자에게 방법을 물음.
- 사용자 결정: "아직 권한 받기 전이니 1번으로 갑시다" → Expiring Consumables 승인 전까지 App Store에서 충전한 코인은 소멸 예외. 승인 후 소멸형 새 상품으로 교체, 기존 상품으로 산 코인은 계속 예외.
- 바꾼 것(ios/Youniya/Screens/SettingsPages.swift, 46 결제·환불 정책): 시행일 2026-12-01(결제·환불만), 3절에 1년 미이용 소멸 + 'App Store에서 충전한 코인은 소멸하지 않음' + 양도 불가, 4절에 '결제했던 수단으로' + 운영자 사정 시 기간 무관 환불. 웹·토스 결제 안내는 iOS 앱엔 원래 없음(그대로).
- 개정 공지는 관리자 콘솔 공지 하나로(사용자 등록) → iOS 코드 변경 없음.
- Debug 빌드, 시뮬레이터 46 확인. 커밋 안 함.
- 남은 일: 사용자가 Account Holder로 Expiring Consumables 신청 / 승인 후 새 상품·결제 화면 만료 표시·잔액·오래된 것부터 차감(서버) 반영한 iOS 빌드.

## API 세션 요청 반영 (코인 소멸 서버 운영 배포 b2f034b·ac2881f 이후)
- 44 개인정보 처리방침: web/privacy.html 새 본문에 맞춤 — 로그인 계정 이메일 수집(이메일 가리기면 가려진 주소), 거래 번호에 토스페이먼츠, 이용 목적에 코인 소멸 안내, 결제 기록 문구, 위탁에 토스페이먼츠(주)·Resend 추가. 시행일은 웹과 같은 2026-11-19로 두되 사용자·토스 세션 확정 후 다시 맞출 것.
