# 컬렉션 격자 아이콘, 알림 권한 요청 (2026-11-06)

- 요청: "드로워에서 컬렉션의 아이콘은 다른 걸로 좀 바꿔주라" → 선택지 중 "새 격자 아이콘" → "그러고나서 다음 것도 진행해줘"(다음 할 일 2번: 알림 권한)

## 1. Icon/grid
- **Figma:** Components 페이지에 `Icon/grid`(296:145)를 새로 만들었다.
  - Icon/archive를 복제해 같은 규칙을 따랐다: 24 프레임, 16pt 글리프, 선 1.8, 둥근 끝, 같은 색 변수
  - 모양은 둥근 칸 4개다.
- **시안:** 67-1 서랍 시안의 컬렉션 아이콘을 Icon/star에서 Icon/grid로 바꿨다.
- **앱:** `iconGrid.imageset`을 추가했다.
  - Figma에서 내보낸 SVG를 썼다. 벡터를 유지하고 템플릿으로 렌더링한다.
  - 서랍의 컬렉션 항목이 이 아이콘을 쓴다.

## 2. 알림 권한
- 새 파일 `App/NotificationAccess.swift`
  - `request()`: 이미 허용됐으면 true다. 처음이면 iOS 권한 창을 띄운다. 거절된 상태면 false다.
  - `openSettings()`: iOS 설정 앱의 YOUNIYA 알림 페이지를 연다.
- 설정 > 알림의 "별 만들기 알림", "새 기능·혜택 알림" 토글
  - 켤 때 먼저 권한을 확인한다.
  - 허용이면 켠다.
  - 거절이면 꺼진 채로 두고 시트를 띄운다: "알림이 꺼져 있어요 / 알림을 받으려면 iPhone 설정에서 YOUNIYA 알림을 켜 주세요." 버튼은 [설정 열기] [닫기]다.
  - 끌 때는 바로 끈다.
- 가입 동의(11)에서 고른 새 기능·혜택 알림 값은 그대로다. 법적 동의와 기기 권한은 따로 다룬다.

## 확인 (iPhone 17)
- 서랍에 격자 아이콘이 보인다.
- 별 만들기 알림을 켜면 iOS 권한 창이 뜨고, 허용 후 토글이 켜진다.

## 확인하지 않은 것
- 거절했을 때 나오는 시트는 화면에서 보지 못했다.
  - 시뮬레이터에서 권한 창 버튼을 누를 수 없었다.
  - `simctl privacy`로 알림 권한을 끌 수도 없었다.
- 별 만들기 알림의 실제 예약(시간, 문구)은 아직 없다(TODO).
- 앱 밖 설정에서 알림을 끈 경우에는 토글을 다시 맞추지 않는다.
