# 로딩 스켈레톤 47–50, 110–112 반영 (2026-11-06)

- 요청: "이제 다음은 뭐할꺼야" → 1번(로딩 스켈레톤)을 추천 → "진행해줘"
- Figma 7개 화면의 블록 크기, 모서리, 간격을 `use_figma`로 읽어 그대로 옮겼다. 블록 색은 #1A2338(`bgSurfaceRaised`)이다.

## 새 파일 `Components/Skeleton.swift`
- `SkeletonBlock`: 회색 블록 하나
- `SkeletonStack`: 블록 묶음
  - 천천히 깜빡인다. 동작 줄이기가 켜져 있으면 깜빡이지 않는다.
  - VoiceOver는 "불러오는 중이에요" 한 번만 읽는다.
- `LoadingGate { 내용 } placeholder: { 스켈레톤 }`: 로딩 중에는 스켈레톤을, 끝나면 내용을 서서히 보여 준다.
- `.simulatedLoad($loaded)`: 아래 버튼까지 바꾸는 화면(111, 112)에서 쓴다.
- 화면별 스켈레톤: `HomeSkeleton`(47), `StarDetailSkeleton`(48), `ListSkeleton`(49·50), `CollectionGridSkeleton`(110), `ReportListSkeleton`(111), `NebulaDetailSkeleton`(112)

| 112 | 77 나의 성운 | 이름 칩·제목·캔버스·정보 표·링크. 아래 두 버튼은 비활성 |

## 언제 보이나
- 백엔드가 목업이어서 기다릴 일이 없다. 그래서 평소에는 스켈레톤이 나오지 않는다.
- 서랍 개발용 "로딩 흉내: 끔/켬"을 켜면 화면이 열릴 때마다 1.5초 동안 스켈레톤을 보여 준다.
- 실행 인자 `-simulateLoading YES`로 켤 수 있다. `-simulateLoadingSeconds 30`처럼 시간을 늘릴 수 있다.

## 확인 (iPhone SE 시뮬레이터)
- 7개 화면을 모두 열어 Figma와 나란히 봤다. 블록 위치와 크기가 맞다.
- 로딩이 끝나면 실제 내용으로 바뀐다(77에서 확인).
- 빌드 성공

## 확인하지 않은 것
- iPhone 17(390pt)에서는 보지 않았다. 블록은 폭을 채우거나 고정 폭이어서 차이가 없을 것으로 본다.
