# 새 화면 확인과 작은 기기(iPhone SE) 점검 (2026-11-06)

- 요청: "다음 진행할 일" → 제안 1(아직 확인하지 않은 새 화면 확인)과 2(작은 기기 점검) → "진행해줘"

## 1. 새 화면을 시안과 나란히 확인 (iPhone 17)
확인한 화면: 98, 108, 96, 97, 117(검색 결과 없음), 118, 119, 105, 106, 107, 113, 114, 109

### 고친 것
- **98 리포트 목록 비어 있음**
  - 빈 화면을 시안처럼 위로 올렸다(위 여백 32 → 8).
  - "마음 망원경 켜기"는 항상 누를 수 있다. 리포트가 없는 띄운 별이 있으면 그 별에서 망원경을 켜고, 없으면 새 별 쓰기로 간다.
- **빈 화면 공통(96·97·103·119·109)**
  - 별 모양을 55% 흐리게 했다.
  - 위 여백을 72 → 48로 줄였다.
- **105·14 다시 쓰기:** 입력칸을 260pt로 고정하고, 버튼을 화면 아래에 두었다.
- **82·109 밝기 흐름:** 기간 칩(최근 별 · 월평균 · 전체)이 시안에서 점 칩으로 바뀌었다. 광장과 같은 `DotChip`을 쓰고, 이제 쓰지 않는 `RangeTag`는 지웠다.
- **109:** 칩과 빈 화면 사이를 시안처럼 48로 넓혔다.
  - 109는 시안대로 띄운 별이 3개 미만일 때 나온다.

## 2. iPhone SE(375×667) 점검
시뮬레이터 "YOUNIYA SE"(iPhone SE 3세대, iOS 26.4)를 새로 만들었다.

### 고친 것
- **탭바 라벨이 화면 아래로 잘림 (모든 탭)**
  - 원인: 오른쪽 서랍 메뉴가 SE 화면보다 길었다. 그래서 전체 레이아웃이 커지고 탭바가 16pt쯤 아래로 밀렸다.
  - 서랍을 화면보다 길면 스크롤되게 바꿨다(`DrawerMenu`).
- **홈이 화면보다 15pt 넓음**
  - 원인: 히어로 별자리를 342pt 고정 캔버스로 그려서, SE의 내용 폭 327pt를 넘었다. 그래서 오른쪽 여백이 10pt로 줄었다.
  - 고정 캔버스를 좁은 화면에서 비율대로 줄이는 `fitCanvas(width:height:)`를 추가했다(`DesignSystem/FitCanvas.swift`). 넓은 화면에서는 그대로 그린다.
  - 적용한 곳: 홈 히어로, 리포트 목록, 기록 탭 별자리 2곳, 06 프리즘(가운데 정렬), 광장 별자리

### SE에서 확인한 화면
- 홈, 성운, 우주 광장, 기록 탭(탭바 전체 보임, 좌우 여백 24)
- 서랍(스크롤), 12 별 상세, 15 삭제 시트, 42 토스트, 82, 109

## 확인하지 않은 것
- SE에서 05 쓰기 → 06 프리즘 → 07 별 카드 흐름. 1,000자를 입력해야 해서 하지 않았다. 06 캔버스에는 `fitCanvas`를 적용했다.
- iPhone 17은 시뮬레이터가 꺼져 있어 다시 보지 않았다. `fitCanvas`는 342pt보다 넓은 화면에서 크기를 바꾸지 않는다.

## 시뮬레이터 데이터
- SE: 샘플 별 "비 오는 날의 안도"를 109 확인용으로 삭제했다.
- iPhone 17: 이전 테스트로 계정 삭제, 내보내기, 코인 충전 기록이 남아 있다.
