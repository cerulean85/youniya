# Figma Mobile 화면 점검과 수정 (2026-11-06)

- 요청: "Figma 화면 이제 더 개선할 게 없는지 확인 해줘" → 찾은 항목 1~5번과 남은 것까지 순서대로 반영
- 대상: Figma `YOUNIYA` 파일 Mobile 페이지(프레임 117개), Components 페이지
- iOS 코드는 이 세션에서 수정하지 않았다.

## 점검한 방법
1. 스크립트로 프레임 117개를 검사했다.
   - 텍스트 1,489개의 문구를 읽었다.
   - 텍스트 스타일과 색 변수가 연결됐는지 확인했다.
   - 프레임 밖으로 나간 요소를 찾았다.
2. 화면 117개 전부를 스크린샷으로 확인했다. 잘림, 겹침, 여백, 아이콘을 봤다.

## 반영한 것
### 1. 화면끼리 모순되는 내용
- **115·117~119 감정 필터:** 차분/깨달음/화남 → 평온/통찰/분노. 분석 화면과 iOS에 맞췄다.
- **21 광장 안내:** "'공명'만" → "'공명'이나 '별빛 한 줄'을". 19(별 공유)는 공명만 맞아서 그대로 뒀다.
- **23:** "별빛 한 줄" → "오늘의 한 줄". 이제 '별빛 한 줄'은 74의 댓글 기능만 가리킨다.
- **03:** "첫 별 띄우기는 무료예요" → "별 띄우기는 언제나 무료예요"
- **32 문의하기:** "답장 받을 이메일" 칸을 추가했다.
- **67 메뉴:** 컴포넌트에 문의하기 항목을 추가했다.

### 2. 예시 숫자 맞추기
- **기준 데이터**
  - 띄운 별 14개, 간직한 별 3개, 곁에 둔 별 3개
  - 첫 별 9월 7일
  - 초신성 기준은 별빛 900으로 했다. Protoss의 CRITICAL HIT, 86의 "별빛 900 이상"과 맞췄다.
- **고친 숫자**
  - 개수: 115~118, 114, 79, 97, 110, 65, 84
  - 별빛 값: 04, 67, 89, 115~117을 별마다 다르게
  - 날짜: 79, 89, 117, 83, 66, 116 달력
  - 그 밖: 26, 81, 82
- **이름 정리**
  - 성장은 '걸음'으로 바꿨다(08, 86).
  - 깊이는 '깊이 N단계'로 바꿨다(72, 73, 75, 78, 80).
- **92:** 별빛 한 줄은 하루 뒤 희미해지므로 "공명은 그대로 간직돼요"로 바꿨다.
- **82 그래프:** 선과 점을 데이터대로 다시 그리고, 날짜 표시를 점 아래로 옮겼다.
- **81:** 8월 표시를 숨겼다.
- **09:** 다른 이의 별 이름을 늦은 밤의 여우자리로 바꿨다.
- **08:** 성운 이름을 느린 저녁의 성운으로 바꿨다(77, 70, 80, 83과 같게).

### 3. 다시 볼 만한 결정
- **104·105:** 1,000자 기준은 그대로 두고 표기만 바꿨다.
  - "14자 · 986자 더 쓰면 띄울 수 있어요"
  - 짧은 글은 조용히 간직하기로 남길 수 있다고 안내한다.
- **공명 숫자:** 다른 사람 글에서는 숨겼다(72, 73, 75, 78, 22).
- **61~64 모션 메모:** 화면 안에서는 숨기고, 화면 위 라벨로 옮겼다.

### 4·5. 표기와 파일 정리
- **표기 통일**
  - 개인정보 처리방침, 임시 저장, 보관돼요로 맞췄다.
  - 품기/간직은 '간직'으로 통일했다.
- **겹쳐 보이던 화면**
  - 22/73, 30/67, 08/65, 23은 iOS에서 모두 쓰여서 지우지 않았다.
  - 22와 73만 이름을 구분했다.
- **빠진 번호(17, 18, 31, 95):** 코드 주석이 번호를 쓰므로 그대로 뒀다.

### 화면 점검에서 찾은 것
- **아이콘 크기 문제(34개)**
  - 체크 아이콘을 줄여도 안쪽 그림이 24px로 남아 삐져나왔다. 같은 문제가 있던 아이콘 34개를 고쳤다(컴포넌트 19개, 화면 15개).
  - 04 "전체 보기 ›"도 이 문제였다.
- **새 아이콘(5개)**
  - `Icon/send`: 74·99·100·101·106의 빈 전송 버튼에 넣었다.
  - `Icon/coin`, `Icon/settings`: 메뉴의 코인과 설정에 넣었다.
  - `Icon/vibrate`, `Icon/sound`: 설정의 진동과 앰비언스 사운드에 넣었다.
- **버튼 빛 번짐:** 감싼 틀 75개가 빛 번짐을 잘라내고 있어서 잘라내기를 껐다.
- **화면별 수정**
  - 54: 별 그림 영역 높이를 220에서 290으로 늘렸다.
  - 10: 범례 테두리를 지웠다.
  - 81: 카드 제목 줄바꿈을 고쳤다.
  - 104: 버튼 위치를 105와 맞췄다.
  - 34: 뒤 화면 제목을 "별 만들기"로 바꿨다.
  - 21: 제목 줄바꿈을 고쳤다.
  - 83: 인용문을 각 별의 문장으로 바꿨다.
- **확대 버튼(7개 화면):** 반투명 배경을 깔았다.
- **지도 안내 글(7개 화면):** 글자 뒤에 그림자를 넣었다.
- **Segmented 컴포넌트:** 선택 표시를 보라색으로 꽉 채운 알약 모양으로 바꿨다(기록 115~119가 함께 바뀜).
- **67:** 메뉴 뒤 화면을 04 내용으로 바꿨다.

## 남은 것
- **iOS 코드 반영:** 위 문구와 숫자가 아직 iOS에 없다.
  - iOS `isSupernova`는 아직 700 기준이다.
  - 한국어 줄바꿈은 `lineBreakStrategy(.hangulWordPriority)`로 처리해야 한다.
- **빈 화면 버튼 규칙:** 새로 만드는 행동은 꽉 찬 버튼, 둘러보는 행동은 테두리 버튼이다. 97, 98, 103, 119를 확인해 보니 이미 이 규칙을 따르고 있다.
