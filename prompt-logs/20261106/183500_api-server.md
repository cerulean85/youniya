## 대응 관계
- **별빛:** 타격 점수(0~999)
- **별의 깊이 / 빛의 선명함 / 마음의 무게:** 직면 깊이 / 명명 정확도 / 귀인 소유권
- **깊이 N단계:** 경험 깊이 7단계
- **초신성:** CRITICAL HIT(900 이상)
- **모듈:** 마음 망원경은 인지 레이더, 성운은 서사 돔이다.

## 구현한 것
- **스택**
  - Python 3.12, FastAPI, SQLAlchemy 2(기본 SQLite), Pydantic, httpx, PyJWT, cryptography, pytest
  - 이 컴퓨터에는 pip와 venv가 없어서 `uv`를 `~/.local/bin`에 설치했다.
- **별빛 프리즘(`youniya_api/prism`)**
  - Protoss 흐름을 그대로 옮겼다: 전처리 → 위기 신호 차단 → 3회 채점 → 중앙값 → 계산식.
  - 채점 기준은 Protoss 그대로 두었다.
  - 화면에 필요한 필드만 더했다: 감정 결, 관측 문장, 망원경 한 줄, 다시 쓰기 질문, 신호 문장.
- **LLM**
  - Protoss처럼 Gemini REST를 쓴다. 채점은 Flash, 리포트는 Pro다.
  - 키가 없으면 결정적으로 동작하는 오프라인 평가기가 대신한다.
- **데이터 보호**
  - 글, 분석, 문의는 Fernet으로 암호화해 저장한다.
  - 11 동의 전에는 글을 저장하지 않는다.
  - 계정을 삭제하면 모든 데이터가 함께 지워진다(CASCADE).
- **인용 검증:** 화면에 다시 보여 주는 모든 문장은 원문에 그대로 있는지 확인한다.
- **코인**
  - 결과가 나온 뒤에만 차감하고, 실패하면 차감하지 않는다.
  - 차감은 원자적이라 잔액이 음수가 되지 않는다.
  - 같은 결제 거래로 두 번 충전되지 않는다.
- **광장**
  - 고른 한 문장만 개인정보를 가린 뒤 공개한다.
  - 다른 사람에게는 점수, 순위, 공명 수를 보여 주지 않는다.
  - 별빛 한 줄은 60자, 성운마다 1인 1개이고 24시간 뒤 사라진다.
  - 상처 주는 말은 거절한다. 신고하면 신고한 사람에게는 바로 가려지고, 3건이 모이면 모두에게 가려진다.
- **앱 상태:** 최소 버전에 못 미치면 426, 점검 시간에는 503을 돌려준다(40, 41).

## 테스트에서 찾은 버그
- **개인정보 가리기 규칙(iOS `PrivacyScan`에서 옮긴 것)**
  - "010-1234-5678로"처럼 조사가 붙은 전화번호를 가리지 못했다. `\b`가 한글을 글자로 보기 때문이다.
  - "강남역에서"처럼 조사가 붙은 장소도 놓쳤다.
  - 서버에서는 고쳤다. iOS에도 같은 문제가 있을 가능성이 높다.

## 추가: App Store 결제 검증
- 요청: "macbook 서버에서는 이제 너가 만드는 API를 연동을 할꺼야. Remote Control을 켜주고 다음 껄 진행해."
- Remote Control은 도구로 켤 수 없어서 `/remote-control`을 안내했다.
- **StoreKit 2 서명 거래 검증(`youniya_api/storekit.py`)**
  - 인증서 체인이 Apple Root CA - G3에서 끝나는지 확인한다. 루트는 SHA-256 지문으로 고정했다.
  - 각 인증서의 서명과 유효기간, Apple 용도 OID를 확인한다.
  - ES256 서명, 번들 ID, 환불·취소 여부, 소모성 상품인지를 확인한다.
- **같은 계정 확인:** `appAccountToken`이 사용자 ID와 다르면 거절한다.
- **테스트:** 가짜 Apple 체인으로 정상, 위조, 다른 앱, 다른 루트, OID 누락, 환불, 구독, 샌드박스 차단을 확인한다.
- **`openapi.json`:** 레포에 넣어서 iOS 쪽이 서버 없이 형식을 볼 수 있게 했다. 코드와 어긋나면 테스트가 실패한다.
- **테스트 결과:** 39개 통과

## 추가: 맥북 연동 준비

- **개발용 로그인:** `POST /v1/auth/dev`를 추가했다. `DEV_LOGIN=1`일 때만 동작한다.
- **실행 스크립트:** `server/dev.sh`를 추가했다. 0.0.0.0:8000에서 서버를 띄우고, 비밀키는 `server/.env`에 둔다. 이 파일은 git에 올라가지 않는다.
- **서버 실행:** 이 컴퓨터에서 서버를 띄웠다.
  - 맥북은 Tailscale 주소(100.126.111.107:8000)로 붙는다.
  - 내부 네트워크 주소(192.168.0.8)는 맥북에서 닿지 않았다.
- **iOS 세션 안내:** "Agent 폴더 표시" 세션에 연동 정보를 보냈다(주소, 인증, 전체 API, 고칠 점).

## 추가: 남은 서버 작업
- 요청: "남은 거 진행해줘"
- **요청 수 제한:** 사용자별·IP별 슬라이딩 윈도로 제한하고, 넘으면 429 rate_limited와 retry_after를 돌려준다. 모델 호출이 있는 API를 중심으로 걸었다.
- **App Store 환불 알림:** `POST /v1/storekit/notifications`(Server Notifications V2)를 추가했다.
  - REFUND가 오면 그 결제의 코인을 한 번만 회수한다. 잔액이 0 아래로 내려가도 회수한다.
  - 서명과 번들 ID를 확인한다.
- **PDF 내보내기:** `GET /v1/me/export?format=pdf`를 추가했다.
  - 나눔고딕(SIL OFL)을 레포에 넣어 PDF에 포함한다.
  - Noto CJK는 CFF 형식이라 reportlab에 넣을 수 없었다.
- **운영자 API:** 신고된 별빛 한 줄 보기, 숨기기·되돌리기, 문의 보기를 추가했다.
  - 운영자가 보거나 한 일은 모두 admin_logs에 남는다(Protoss 3장).
  - ADMIN_TOKEN이 없으면 운영자 API는 404다.
- **테스트 결과:** 45개 통과
- **개발 서버:** 새 코드로 다시 띄웠다(API 경로 47개).
