## 개발용 버튼 "긴 예시 글 쓰기" (서랍)
- 1,058자 예시 글("느려도 결국 닿는 하루")을 임시 글로 저장하고, 05 쓰기 화면을 바로 연다.
- 별을 띄우려면 1,000자가 필요해서, 손으로 입력하지 않고 흐름을 확인하려고 만들었다.
- `AppModel.fillLongDraft()`, `DrawerMenu.DevAction.longDraft`

## 확인한 흐름 (iPhone 17)
- 05 → 06(4.2초 애니메이션) → 첫 별 탄생(별이 처음일 때만) → 07
- 두 번째 별부터는 05 → 06 → 07로 바로 간다.
- 세 화면 모두 시안과 레이아웃이 맞다. 07의 숫자와 감정 칩은 분석 값에 따라 달라진다.

## 고친 것
- **06 아래 안내 문구:** "보존돼요" → 시안 문구 "보관돼요"
- **05 글자 수**
  - 1,000자 이상: "1,058 / 1,000자" → 시안 05처럼 "1,058자"
  - 1,000자 미만: 시안 104처럼 "14자 · 986자 더 쓰면 띄울 수 있어요"

## 확인하지 않은 것
- 1,000자 미만 문구는 빌드만 확인했다. 화면에서는 보지 않았다.
- iPhone SE에서는 이 흐름을 보지 않았다. 06 캔버스에는 이미 `fitCanvas`가 적용되어 있다.
