## 고친 문제
- clone()이 섹션 밖(페이지)에 놓여 섹션 안으로 옮김. 이후 newFrame에서 sec.appendChild.
- 설정 샘플 로그인 계정에 사용자 이메일 일부가 들어가 "Google 계정"으로 바꿈.
- 설정 "계정 영구 삭제" Danger 버튼이 화면에서 가장 강해 Ghost로 낮춤(확인 단계는 다이얼로그에서).
- 문의 개인정보 문구를 실제 코드 문구로 교체, 코인 내역의 지어낸 항목 제거.
- 스켈레톤 행 높이(빈 auto-layout 기본 100px) 수정.
