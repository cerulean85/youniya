# 운영자 콘솔 Admin v2 디자인 구현 (2026-11-17)

- 근거: Figma Admin v2 (660:2) A2-01~A2-21 스크린샷과 대시보드·신고 상세 design context.
- 바꾼 곳: admin/ 아래만. /v1/admin API 계약, 역할 검사, NotConnected, noindex·X-Frame-Options는 그대로.
- 사이드바: 대시보드 / 처리할 일 / 돈 / 서비스 / 기록·권한으로 묶고 신고 대기·새 문의 건수를 보여 줌(데이터 있을 때만). moderator는 여전히 3개만.
- 화면: 카드 대신 제목+1px 선, 숫자는 세로 구분선 한 줄, 표는 전체 폭, 상태 알약 색 정리, 24시간 넘은 경과는 노란색.
- 대시보드: '지금 처리할 일'을 맨 위에 두고, 숫자 줄(충전 중복 제거), 알림 표 + 오늘의 결제 순서.
- 신고 상세: 버튼별 대화상자를 오른쪽 라디오 패널(이 별 / 이 별지기 / 기록만) + 사유 + 실행 버튼 하나로 바꿈. 서버 액션·문구는 그대로.
- 별지기 상세: 조치를 묶음별 텍스트 행으로, 환불 대화상자에 별지기·결제·남은 코인 전→후와 '금액 환불' 버튼, 코인 회수 버튼은 'N코인 회수'.
- 운영자 초대 링크와 초대 계정 비밀번호는 복사 버튼이 있는 결과 대화상자로 보여 줌.
- 사유 대화상자는 오류가 나면 입력을 지우지 않고 열린 채로 둠.
- 로그인·설정·권한 없음·서버 연결 대기·빈 화면을 프레임대로 바꿈.
- 확인: tsc, eslint, next build 통과. ADMIN_MOCK=1로 띄워 Chrome에서 로그인(오류 포함), 대시보드, 신고 목록·상세(내리기 실행), 별지기 목록·상세(환불 대화상자, 코인 회수 실행), 문의, 코인, AI, 별빛 측정, 초대 계정, 공지·점검, 운영자(초대 링크 대화상자), 권한 없음 화면을 확인.
