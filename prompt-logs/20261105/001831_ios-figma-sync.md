# Figma Mobile 시안 변경 반영 (2026-11-05)

- 요청: "Figma의 Mobile 디자인 시안이 변했기 때문에 그동안 구현했던 페이지와 차이가 있을꺼야. 확인해서 시안과 다른 부분을 구현에 반영해줘."

## 확인 방법
1. 구현한 화면 34개(01–29, 32, 33, 37, 67, 87)의 현재 Figma 스크린샷을 받았다.
2. 어제 받아 둔 시안(01–16, 23–37)과 픽셀로 비교해, 바뀐 화면과 위치를 찾았다.
3. 텍스트 스타일과 컴포넌트 크기 목록을 읽어 공통 변경을 확인했다.
4. 어제 시안이 없는 17–22는 앱 화면과 직접 나란히 비교했다.
5. 수정한 뒤 시뮬레이터 화면을 찍어 Figma와 나란히 다시 비교했다.

## 공통 변경 (모든 화면에 영향)
- 텍스트 스타일
  - Body/S: 12/18 → 13/20
  - Caption: 11/16 → 12/18
  - 새 스타일 Caption/Tab(11/16): 탭바 라벨과 설정 안내 문구에 쓴다.
- 버튼 높이 44 → 48 (Primary, Secondary, Ghost, 새 Danger)
- 목록 카드(Item)와 Star Row 높이 76 → 78
- Cosmos BG(은은한 성운 배경)가 더 많은 면에 들어갔다.
  - 03 빈 슬롯, 06 측정 상자, 07 망원경 안내, 08 숫자 카드, 09 세그먼트, 10 리포트 카드 4종, 13 품기 표시, 14 지난 질문과 입력칸, 16 비교 카드, Link Chip
- Link Chip: Cosmos BG, 높이 32 (`Components/LinkChip.swift`로 공용화)
- Today Star Card 테두리: 보라 단색 → 보라에서 회색으로 가는 그라데이션

## 화면별 변경
- 03: 빈 슬롯 원에 Cosmos BG를 넣고, 점선 간격을 4/6으로 바꿨다.
- 08 나의 성운
  - 숫자 카드 라벨에 "›"를 붙이고, 누를 수 있게 했다(자리표시 페이지).
  - 링크 칩 "나의 은하수"를 추가했다.
- 13: 품기 표시 원에 Cosmos BG를 넣고, 점선 간격을 3/6으로 바꿨다.
- 14: 지난 질문과 입력칸을 목록 카드 스타일(그라데이션 테두리, Cosmos BG)로 바꿨다.
- 15: "영구 삭제"가 빨간 Danger 버튼이 되었다(#F98B8B → #E35D5D, 붉은 빛).
- 17: 부제 아래에 "밝기 흐름 보기 ›" 칩을 추가했다(82 밝기 흐름 자리표시 페이지로 이동).
- 제목–부제 간격 4 → 16: 20, 22, 23, 24, 28, 32 (Figma 측정값에 맞춤)
- 21: 상단 그림 위 여백(32)을 없앴다. 시안보다 30pt 아래에 있었다.

## 바꾸지 않은 것
- 67 메뉴: Figma는 팝업 카드지만 어제 시안과 같다. 앱은 사용자가 요청한 오른쪽 서랍을 유지한다.
- 09 세그먼트: Segmented 컴포넌트는 모서리 12로 바뀌었지만, 09 화면 자체는 여전히 알약 모양이라 그대로 두었다.
- 기존부터 있던 차이(이번 변경과 무관)
  - 14 입력칸이 화면을 채운다(시안은 260 고정).
  - 하단 시트가 시안보다 약 20pt 낮다.
  - 하단 버튼이 홈 인디케이터만큼 위에 있다.
