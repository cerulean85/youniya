# 성운 그리기 흐름: 51–55, 84, 85 (2026-11-05)

- 요청: "그렇게 해줘" (76·77·83 커밋한 뒤 성운 그리기로)
- 먼저 76·77·83 작업을 커밋했다: `969aa58`

## 흐름 (`Screens/NebulaDrawing.swift`)
```
51 시작 → 84 모양 고르기 ─ 틀(고래·등대·나무·새·꽃) → 85 손님별 (빈 자리가 있을 때) → 54 이름 → 55 완성
                       └ 직접 그리기 → 52 별 고르기 → 53 잇기 → 54 → 55
```
- **들어가는 곳:** 08 "성운 그리기" 칩, 77 "성운 그리기" 칩
- **뒤로 가기:** 뒤로 버튼과 가장자리 스와이프는 한 단계씩 돌아간다. 51에서 누르면 흐름을 닫는다.
- 55에는 뒤로 버튼이 없다(시안대로).

## 화면별
- **51:** 띄운 별을 회색 점으로 깐 배경, "시작하기" / "나중에". 띄운 별이 없으면 시작할 수 없고 "별을 먼저 띄워 주세요"가 나온다.
- **84 모양 고르기**
  - 타일 6개: 고래·등대·나무·새·꽃·직접 그리기. 각 모양의 작은 그림은 Figma `Mini` 좌표 그대로다.
  - 미리보기는 고른 모양의 점선 외곽선이다. 자리 18개 중 앞쪽에 내 별(띄운 순서대로, 감정 색, 5/7/9pt)을 놓고, 나머지는 점선 빈 자리로 둔다.
  - 별이 18개보다 많으면 최근 18개만 놓는다.
  - 범례: "내 별 N · 빈 자리 M · 다음 별을 기다려요"
- **85 손님별**
  - 광장에서 공명했던 별 후보 4개(목업, TODO: 광장 API)를 체크해서 빈 자리에 들인다. 최대 5개이고, 빈 자리 수를 넘을 수 없다.
  - 미리보기는 고른 모양 그대로이고, 손님별은 금 고리로 표시한다(시안은 물결 모양 예시).
  - 고르지 않으면 버튼이 "손님별 없이 이어 가기"가 된다.
- **52 별 고르기:** 띄운 별(최근 12개)을 Figma 위치에 놓고, 누르면 금색이 된다. 2개 이상 골라야 다음으로 간다.
- **53 잇기**
  - 별에서 별로 손가락을 끌면 선(청록)이 생긴다. 별을 하나 누르고 다른 별을 눌러도 이어진다. 이을 때 가벼운 진동이 온다.
  - "다시 그리기"는 선을 지운다.
  - VoiceOver에서는 "고른 순서대로 잇기" 동작으로 잇는다.
- **54 이름 짓기:** 그린 성운 아래에 이름 칸(포커스되면 보라 테두리와 청록 빛)이 있다. 이름이 비어 있으면 저장할 수 없다.
- **55 완성**
  - 「이름」과 그린 성운을 보여 준다.
  - "우주 광장에 나누기": 공유 표시(모의)를 하고 광장 탭으로 가서 "우주 광장에 나눴어요" 토스트를 띄운다.
  - "홈으로": 밤하늘 탭으로 간다.

## 저장

- 마지막으로 그린 성운의 이름이 **08·77·83의 성운 이름**이 된다. 없으면 기본값 "늦은 밤의 등대자리"를 쓴다.
