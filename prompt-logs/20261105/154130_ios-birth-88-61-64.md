# 연출 화면: 88 망원경 관측 · 61–64 별 탄생 (2026-11-05)

- 요청: "진행해줘" (88, 61–64)
- 코드: `Screens/BirthScreens.swift`

## 들어가는 곳
- **88:** 망원경을 켜면 25 "별들을 바라보는 중이에요"를 1.6초 보여 준 뒤, 글이 있는 별이면 88로 넘어간다. 글이 없으면 전처럼 바로 리포트로 간다.
- **61–64:** 별을 띄우면 06 프리즘 분석 다음, 07 별 카드 앞에 나온다. 다시 쓰기(14)는 16 비교 화면 앞에 나온다.
  - 흐름: `05 → (37) → 06 → 61–64 → 07 또는 16`

## 88 망원경 관측 (`TelescopeObserveView`)
- 위쪽: 닫기(✕), "마음 망원경"
- 제목 "문장 사이를 비추는 중"과 부제
- **상태:** 금빛 점과 "감정 신호 N개를 찾았어요"(찾기 전에는 "감정 신호를 찾는 중"), "렌즈 N / 3"
- **일기 카드**
  - 일기를 문장으로 나눠 최대 8개를 보여 준다.
  - 청록 빛줄기가 위에서 아래로 지나가고, 지나간 자리의 감정 문장에 보라 상자로 불이 켜진다.
- **렌즈 태그 세 개:** 지나간 렌즈에는 ✓가 붙고, 지금 렌즈는 보라로 강조된다.
- **시간:** 렌즈마다 1.6초씩 세 번 지나간 뒤 리포트로 넘어간다(모의).
- **"백그라운드로 두기" / ✕:** 리포트를 준비해 두고 나간다.
- **불 켜질 문장(모의):** 마음·기다림·쉬고 싶음 같은 단어가 있는 문장을 최대 3개 고른다. 없으면 마지막 문장을 고른다. TODO: 분석 API가 정한다.
- **동작 줄이기:** 빛줄기 없이 모두 켠 상태로 2초 뒤 넘어간다.

## 61–64 별 탄생 (`StarBirthView`)
- Figma 메모의 시간 그대로 움직인다.
  - 0.0s "마음을 모으는 중": 금빛 점 6pt
  - 0.6s "빛이 번져요": 점 16pt, 금빛 후광 90pt
  - 1.2s "별이 모양을 이뤄요": 별 40pt, 보라 후광 140pt
  - 1.7s "별이 떴어요": 별 48pt, 금빛 후광 150pt, 청록·분홍 작은 별, "별 보기" 버튼
- 제목은 64에서 위로 올라간다(시안대로).
- 끝나면 VoiceOver로 "별이 떴어요"를 읽어 준다. 동작 줄이기를 켜면 바로 64가 나온다.
- Figma의 "모션 0.6s · first-light" 같은 메모 글자는 화면에 넣지 않았다.

## 확인
- **시뮬레이터에서 확인:** 별을 띄워서 06 → 61 → 62 → 64 → 07이 이어지는 것, 망원경을 켜서 25 → 88 → 10 리포트가 이어지는 것
- **88:** 시안과 나란히 확인했다. 테스트 글이 영어라 불 켜진 문장은 마지막 문장 하나뿐이었다.
- **확인하지 않은 것**
  - 63 순간 캡처
  - 동작 줄이기 상태
  - 88의 "백그라운드로 두기"
  - 다시 쓰기 경로
- **시뮬레이터 정리:** 테스트 별은 백업에서 되돌려 지웠다. 망원경 테스트로 코인 30개가 쓰였다.
