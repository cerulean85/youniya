# 34–42 상태·오류 화면 (2026-11-05)

- 요청: "34-42부터 진행"
- Figma: 34 작성 중 나가기, 35 연결 끊김, 36 분석 실패, 38 결제 미완료, 39 로그인 만료, 40 업데이트 필요, 41 서비스 점검, 42 토스트 모음
  - 37 위기 돌봄은 이미 만들어 두었다.

## 공용 부품 (`Screens/StatusScreens.swift`)
- **`StatusView`:** 35, 36, 38–41이 같이 쓰는 화면이다.
  - 아이콘 원, 제목(h2), 설명(bodyM), 버튼(primary, secondary, ghost)을 화면 가운데에 놓는다.
  - 화면 전체 기준으로 가운데에 놓아서 Figma 위치와 같다.
- **`StatusHero`:** 궤도 두 개, 보라 원, 금색 아이콘, 금색·청록 별이다.
  - Figma 아이콘 틀은 30pt지만, 그림은 그 안 왼쪽 위에 24pt로 놓인다. 앱도 그대로 24pt로 그린다.
- **새 아이콘:** `iconWifiOff`, `iconWarning`, `iconUser`. Figma SVG를 @3x PNG로 만들었다.
- **`ToastCard`와 `.toastCard($message)`:** 42 카드형 토스트다(제목, 선택 설명). 2.2초 뒤 사라지고 VoiceOver로 읽어 준다.

## 화면별 동작
| 화면 | 언제 | 버튼 |
|---|---|---|
| 34 | 05에서 글을 쓴 채로 "닫기" | 임시 저장하고 나가기 / 계속 쓰기 / 버리기(Danger, 임시저장까지 지움) |
| 35 | 분석(06)이 끝날 때 연결이 끊김 | 다시 시도. 아직 끊겨 있으면 42 "연결을 확인해 주세요" 토스트 |
| 36 | 분석 실패 | 다시 시도(06 다시) / 조용히 품기(분석 없이 품은 별로 바꾸고 13으로) |
| 38 | 코인 충전 결제가 끝나지 않음 | 다시 결제하기 / 닫기 |
| 39 | 로그인 만료 | 로그인(데이터는 두고 로그인 화면으로) |
| 40 | 업데이트 필요 | 업데이트(App Store 열기. 실제 앱 링크는 TODO). 닫는 버튼 없음 |
| 41 | 서비스 점검 | 닫기 |

- **39–41:** `model.appNotice`로 앱 맨 위를 덮는다(RootView).
- **42 토스트:** 별을 영구 삭제하면 "삭제되었어요 / 되돌릴 수 없어요"가 뜬다. 35 다시 시도 실패 때도 쓴다.
  - "별을 띄웠어요"와 "조용히 품었어요"는 07과 13 완료 화면이 이미 같은 말을 해서 쓰지 않았다.
- **스와이프 뒤로 가기:** 34는 묻지 않고 임시 저장한 뒤 나간다(기존 동작).

## 서버 없이 확인하는 방법 (개발용 서랍 메뉴)
- **"실패 흉내":** 누를 때마다 없음 → 연결 끊김 → 분석 실패 → 결제 미완료 → 없음으로 바뀐다.
  - 켜 둔 동안 계속 실패한다.
  - 메모리에만 있어서 앱을 다시 켜면 "없음"이 된다.
- **"39 · 40 · 41":** 누르면 해당 안내 화면을 띄운다.

## 확인
- **시뮬레이터에서 시안과 나란히 확인:** 34, 35, 36, 38, 39, 40, 41
- **아이콘 크기:** 24pt로 고친 뒤 39에서 다시 확인했다.
- **동작 확인**
  - 34 버리기 → 임시저장 파일이 지워지고 홈으로 간다.
  - 35 다시 시도 → 토스트가 뜬다.
  - 36 조용히 품기 → 품은 별(분석 없음)이 되고 13으로 간다.
  - 39 로그인 → 로그인 화면으로 간다.
  - 41 닫기가 동작한다.
  - 별 삭제 → 42 토스트가 뜬다.
- **확인하지 않은 것**
  - 38 "다시 결제하기"를 실패 흉내 없이 누르는 경우
  - 40 업데이트 버튼(시뮬레이터에 App Store가 없음)
- **테스트 뒤 되돌린 것:** 별 데이터를 백업으로 되돌려 테스트 별을 없앴다.
