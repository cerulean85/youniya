# 시안 반영 마무리 + 설정 하위 페이지 (2026-11-05)

- 요청: "추천대로 진행해줘"
  - 1단계: 지난 반영에서 직접 확인하지 못한 11개 화면을 확인한다.
  - 2단계: 설정 하위 페이지를 만든다.

## 1. 남은 11개 화면 확인
- 대상: 05, 11, 23, 24, 25, 27, 28, 29, 32, 33, 87
- 방법: 시뮬레이터 화면을 찍어 오늘 Figma 시안과 나란히 비교했다.
- 그대로 맞은 화면: 05, 23, 25, 26, 28, 29, 33
- 27 정렬 시트: 주가 2개 이상일 때만 열린다. 같은 시트 부품을 쓰는 24·29로 대신 확인했다.

### 고친 것
- **색 토큰 변경 (Figma 변수)**
  - `text/tertiary`가 #64748B에서 #8090A6(neutral/450)으로 바뀌었다.
    - 설정 섹션 제목, 화살표, 안내 문구가 더 밝아진다.
    - `TextTertiary.colorset`을 고쳤다.
  - 새 토큰 `brand/primary-text`(#9C74F7)가 생겼다.
    - Figma에서 이 토큰을 쓰는 곳: 06 상태 칩, 07 "마음 망원경", 09 "공명", 10 "스스로 물어볼 질문"
    - `BrandPrimaryText.colorset`을 추가하고 이 네 곳에 적용했다.
- **11 가입 동의**
  - "전체 동의" 줄에도 화살표를 붙였다(누르면 전체 동의가 켜지고 꺼진다).
  - 화살표를 template 이미지로 바꿔 text/tertiary 색을 입혔다.
- **32 문의하기:** "여기에 적어 주세요" 안내 글자를 text/secondary로 바꿨다(시스템 기본 회색보다 밝다).

### 그대로 둔 차이
- **한 줄짜리 글자의 위아래 여백**
  - `textStyle`은 줄과 줄 사이만 넓히고, 한 줄 글자의 위아래 여백(half leading)은 넣지 않는다.
  - 그래서 카드 안 제목과 설명, 시트 제목과 설명 사이가 시안보다 2–4pt 좁다(28, 24 등).
  - 전체를 고치면 이미 맞춘 화면이 모두 조금씩 밀려서, 새 화면에만 `textStyleBox`를 썼다(아래 참고).
- **29 코인 부족 시트:** 시안은 시트 뒤 화면이 비어 있고, 앱은 24 화면이 보인다. 같은 시트에서 내용만 바뀌는 구조라 그대로 뒀다.

## 2. 설정 하위 페이지
| 화면 | 들어가는 곳 | 구현 |
|---|---|---|
| 43–45 약관 문서 | 설정 › 약관 및 정책, 11의 각 화살표 | `PolicyDocView` |
| 46 결제·환불 정책 | 설정 › 약관 및 정책, 28 정책 링크 | `PolicyDocView` |
| 68 우주의 색 | 설정 › 우주의 색 | `SkyColorView`. 적용하면 앱 전체 배경 성운 색이 바뀐다. |
| 91 계정 영구 삭제 | 설정 › 계정 영구 삭제 | 시트. "영구 삭제"는 Danger 버튼이고, "먼저 내보내기"는 93으로 넘어간다. |
| 92 모든 공유 거두기 | 설정 › 모든 공유 거두기 | 시트(버튼 2개). 공유한 별 개수를 보여 준다. |
| 93 데이터 내보내기 | 설정 › 데이터 내보내기 | 시트. 텍스트나 PDF 파일을 만들고 T1 토스트를 띄운다. |
| 94 소리 고르기 | 설정 › 소리 고르기 | 시트. 밤바람 또는 미세한 성간 주파수를 고른다. |

### 세부
- **우주의 색 (`DesignSystem/SkyTheme.swift`)**
  - 다섯 테마의 세 색은 Figma 스와치 값을 그대로 썼다.
  - `AppSettings.sky`에 저장되고, 루트에서 `skyTheme` 환경값으로 내려간다.
  - StarField: 기본(보랏빛)은 원래 이미지를 쓰고, 다른 테마는 같은 이미지에 테마 색을 입힌다.
  - Cosmos BG(카드, 시트, 버튼)의 세 빛도 테마 색을 따른다.
- **약관 문서**
  - 문서 목록 화면은 시안에 없다. 그래서 "약관 및 정책"을 누르면 네 문서를 고르는 시스템 다이얼로그가 뜬다.
  - 11의 "(선택) 새 기능·혜택 알림" 문서는 시안에 없어 자리표시 페이지로 둔다.
  - 글 간격이 Figma와 같도록 `textStyleBox`를 새로 만들었다. `textStyle`에 줄 높이만큼의 위아래 여백을 더한다.
- **계정 영구 삭제 (모의)**
  - 기기의 별, 임시저장, 코인 내역, 저장한 한 줄, 설정, 동의, 첫 망원경 무료 여부를 모두 지우고 로그인 화면으로 돌아간다.
  - 서버 계정 삭제는 TODO.
- **데이터 내보내기**
  - `Documents/YOUNIYA-날짜.txt|pdf`에 저장한다.
  - 파일 앱에서 보이도록 Info.plist에 `UIFileSharingEnabled`와 `LSSupportsOpeningDocumentsInPlace`를 켰다.
  - 일기 원본(`Application Support`)은 파일 앱에 드러나지 않는다.
- **모든 공유 거두기 (모의):** 모든 별의 `sharedToPlaza`를 끈다. 광장 API는 TODO.
- **소리:** 설정 아래 안내 문구를 소리마다 따로 쓴다. 밤바람이면 Figma 문구 그대로 나온다. 실제 소리 재생은 TODO.
- **토스트:** `ToastView`와 `.toast($message)`를 추가했다. 2초 뒤 사라지고, VoiceOver에도 읽어 준다.
- **시트 부품:** `ActionSheetContent`에 `destructive`(Danger 버튼)를 추가하고, 셋째 버튼을 없앨 수 있게 했다.

## 확인
- **시뮬레이터에서 시안과 나란히 확인:** 43, 46, 68, 91, 92, 93, 94, 토스트
- **동작 확인**
  - 오로라 테마를 적용하자 배경이 초록으로 바뀌었다.
  - 소리를 고르면 값과 안내 문구가 바뀐다.
  - 91 "먼저 내보내기"를 누르면 93이 열린다.
  - PDF는 2쪽으로 만들어졌다.
- **확인하지 않은 것:** 91 "영구 삭제"는 시뮬레이터 데이터가 지워져 누르지 않았다. 44, 45는 43과 같은 화면이라 따로 열지 않았다.
- **테스트 뒤 되돌린 것:** 테마, 소리, 별 데이터, 내보낸 파일. 테스트로 만든 별 두 개는 별 데이터를 백업에서 복원해 없앴다.
- **되돌리지 못한 것:** 망원경 테스트로 코인 30개가 쓰였고, 코인 내역에 한 줄 남았다.
