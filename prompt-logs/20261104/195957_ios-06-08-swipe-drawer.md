  - 06 Prism Analysis (9:150)

  - 08 My Nebula (11:173)
  - 메뉴: 67 Home · Menu Open (22:1411)의 Menu Popup

## 해석
- 왼쪽 슬라이드: 화면 왼쪽 가장자리에서 오른쪽으로 끌면 이전 화면으로 돌아간다. 페이지가 손가락을 따라 움직인다.
- 오른쪽 슬라이드: 화면 오른쪽 가장자리에서 왼쪽으로 끌면 메뉴 드로어가 열린다.
- Figma 메뉴는 팝업 형태지만, 요청에 맞춰 같은 항목과 스타일을 오른쪽에서 밀려 나오는 드로어 패널로 만들었다.

## 과정
1. Figma에서 디자인(`get_design_context`)과 애니메이션(`get_motion_context`)을 읽었다.
2. SVG 52개를 PNG로 바꿔 넣었다: 프리즘, 빔, 감정 마커, 성운 별 등.
3. 폰트를 추가했다: NotoSansKR-Light (07 별빛 숫자용).
4. 새 디자인 토큰을 추가했다.
   - 색: BorderFocus, StarClear, BrandWarm
   - 텍스트 스타일: metric, observation, bodyS
5. 화면 이동 구조를 바꿨다.
   - 05는 시트가 아니라 오른쪽에서 밀려 들어오는 페이지가 됐다.
   - MainView가 `Route`(compose / starCard / page) 단위로 페이지를 띄운다.
6. 새 파일
   - `DesignSystem/EdgeSwipe.swift`: `edgeSwipeBack`(왼쪽 가장자리 → 뒤로), `edgeSwipeDrawer`(오른쪽 가장자리 → 드로어)
   - `Screens/PrismAnalysisView.swift`: 06
   - `Screens/StarCardView.swift`: 07, `ComposeFlowView`(05→06→07)
   - `Screens/NebulaView.swift`: 08
   - `Components/TodayStarCard.swift`: AxisMeter, TodayStarCard
   - `Components/DrawerMenu.swift`
7. 수정한 파일
   - AppModel: `StarAnalysis` 추가, 성운 통계
   - Buttons: Ghost 버튼, FlowTopBar
   - MoodChip: 표시 전용 MoodTag 분리
   - StarMakingView: 닫기·발행을 상위 흐름에 맡김
   - HomeView: 분석된 별을 누르면 07 카드가 열림
   - MainView

## 동작
- 05 → 06: "별 띄우기"를 누르면 프리즘 연출이 약 4초 재생된다.
  - 빛 → 프리즘 → 7개 빔 → 감정 마커 → 게이지 순서다. Figma 2초 타임라인을 한 번 재생하고 마지막 상태를 유지한다.
  - 끝나면 07로 넘어간다.
- 07: 별빛 숫자, 3축 게이지, 관찰 문장, 감정 태그, 마음 망원경 안내.
  - "나의 성운 보기"를 누르면 성운 탭으로 간다.
  - "마음 망원경 켜기"는 자리표시 페이지를 연다.
- 08 (성운 탭): 별자리 캔버스(별 반짝임 포함)와 통계 3개를 보여준다.
  - 떠 있는 별 / 깊은 별 / 초신성 수를 실제 별 목록에서 센다.
  - 다음 단계까지 남은 깊은 별 수를 계산해 표시한다.
- 뒤로 스와이프
  - 05: 닫힌다 (초안 저장).
  - 06: 분석 중이라 동작하지 않는다.
  - 07: 닫힌다.
  - 메뉴 항목 페이지, 홈에서 연 별 카드: 이전 화면으로 돌아간다.
  - 화면 너비의 25% 이상 끌거나 빠르게 튕기면 확정되고, 아니면 제자리로 돌아온다.
- 드로어: 오른쪽 가장자리 스와이프나 메뉴 버튼으로 연다.
  - 배경 탭이나 오른쪽으로 밀면 닫힌다.
  - 항목: 별빛 기록, 보관함, 마음 망원경, 코인, 설정 (모두 자리표시 페이지)
  - 아래에 개발용 버튼(샘플 별, 비우기, 로그아웃)이 있다.

## 검증 (iPhone 17 Pro 시뮬레이터)
- 빌드 성공
- 05 → 06 → 07 흐름을 확인했다. 06 문구가 잘려 세로 여백을 줄였다.
- 오른쪽 가장자리 스와이프로 드로어가 열리고, 메뉴 항목 페이지가 열렸다.
- 왼쪽 가장자리 스와이프로 페이지가 손가락을 따라 움직이고 홈으로 돌아왔다.
  - 처음 임계값(33%)에서는 짧은 스와이프가 되돌아가서 25%로 낮췄다.
- 08 화면을 Figma와 비교했다.
