## 작업 중 발견한 Figma 변경
21:30 비교 이후 Figma에서 "Cosmos BG"(은은한 성운 빛 + 별 먼지)가 여러 컴포넌트에 새로 들어갔다.
- 해당 컴포넌트: Secondary 버튼, Tab Bar v2, Google 로그인 버튼, Star Row, Today Star Card, Nebula Card, Bottom Sheet, Menu Popup, Text Field, Toast, Coin Package Card, Segmented, Search Bar
- 04 홈을 다시 받아 21:30 이미지와 비교해, 별 목록과 탭바에 실제로 적용된 것을 확인했다.

### 반영
- `DesignSystem/CosmosBackground.swift`를 추가했다.
  - 보라·분홍·청록의 은은한 빛 3개와 별 먼지를 Canvas로 그린다.
  - 배치는 문자열 시드로 정해진다. 화면마다 다르지만 다시 그려도 같다.
  - 색과 불투명도는 Figma 채움 값을 썼다.
  - 앱의 별 목록과 Figma를 나란히 놓으니 앱 쪽 보랏빛이 진해 보여, 전체 세기를 0.6배로 낮췄다.
- 앱에서 쓰는 부품에 모두 적용했다.
  - Secondary 버튼 (Figma처럼 약 절반 세기)
  - 탭바, Google 로그인 버튼, 별 목록 행, 오늘의 별 카드, 우주 광장 카드, 메뉴 드로어
  - 하단 시트 배경 (`SheetBackground`): 15 삭제 시트, 19 공유 시트
- 아직 화면이 없어 적용하지 않은 부품: 입력칸, 토스트, 코인 카드, 세그먼트, 검색창
- 별 먼지는 Figma의 SVG를 그대로 쓰지 않고, 같은 색·크기·밀도로 그린다. 카드 크기가 화면마다 달라서다.

## 17–19
- `Screens/RecordsView.swift`
  - `RecordsView`(17): 제목, 부제, 반짝이는 별자리, 모든 별 카드(띄운 별은 "별빛 N", 품은 별은 "조용히 품음")
    - 메뉴의 "별빛 기록"을 누르면 뒤로 버튼이 있는 페이지로 열린다.
    - 탭바의 "기록" 탭에서는 뒤로 버튼 없이 보인다.
  - `KeptView`(18): 궤도 그림 + 품은 별 목록 + "모두 내보내기"(공유 창). 비었을 때 안내 문구를 보여준다.
  - `RecordCard`: 보라 테두리, 그라데이션, 성운 배경, 회전하는 별 아이콘
  - `ShareConsentSheet`(19)
- `StarGlyph`: 별 목록 아이콘. 12초에 한 바퀴 시계 방향으로 돈다.
  - Figma 애니메이션 데이터는 6초에 60°였지만, 컴포넌트 설명("12초에 한 바퀴, 끊김 없이")을 따랐다.
- 19 공유
  - 12의 "우주 광장에 나누기" → 19 시트
  - 익명으로 나누기: 공유 상태로 저장하고, 버튼이 "우주 광장에서 거두기"로 바뀐다.
  - 내용 먼저 확인: 20 개인정보 확인 자리표시 페이지
  - 나누지 않기: 닫는다.
  - 공유는 아직 기기 안의 표시일 뿐이고, 서버로 보내지 않는다.
- 모델
  - `sharedToPlaza`(선택값이라 예전 저장 파일도 그대로 읽힌다), `shortDateText`, `setShared`
- 화면 이동 구조를 바꿨다.
  - 이전에는 한 단계만 기억해서, 17 → 12로 간 뒤 뒤로 가면 홈으로 갔다.
  - 이제 페이지가 쌓여 17 → 12 → 뒤로 가면 17로 돌아온다.
  - 끝난 화면(07 → 10, 13 → 12 등)은 쌓지 않고 교체한다.
