# iOS 앱 05 별 만들기 화면 구현

- 일시: 2026-11-04 19:47
- 요청: "05 진행"
- 대상: Figma `05 Star Making` (9:109)
- 결과물: `ios/Youniya/Screens/StarMakingView.swift` 외

## 과정
1. Figma `get_design_context`로 디자인을 읽었다.
   - `get_motion_context`(9:124) 결과, 배경 외에 애니메이션은 없었다.
2. Figma의 Button Primary가 단색에서 그라데이션으로 바뀐 것을 확인했다.
   - Default: #9B72F8 → #7A4BE8
   - Hover: #8F67FF → #652EFF
   - `PrimaryButtonStyle`을 그라데이션으로 바꿨다. 01~04의 Primary 버튼에도 같이 적용된다.
3. 새 디자인 토큰을 추가했다.
   - 감정 색: EmotionCalm / Sorrow / Anger / Insight
   - 감정 틴트: 각 색 16%
   - 그라데이션 색 4개
   - 텍스트 스타일: H2(Serif Medium 22/32), Journal/Body(Serif Regular 16/30)
   - 폰트: NotoSerifKR-Regular.otf 추가
4. 칩의 점 SVG는 단색 8pt 원이라 SwiftUI `Circle`로 그렸다.
5. 컴포넌트와 화면을 만들었다.
   - `MoodChip`: Figma Chip
   - `SecondaryButtonStyle`: 보라 테두리 버튼
   - `StarMakingView`
6. 연결을 바꿨다.
   - 03 "첫 별 만들기", 04 "오늘의 별 만들기", 탭바 연필 버튼(FAB)이 모두 05를 전체 화면으로 연다.
   - 기존 임시 시트는 없앴다.
   - 개발용 메뉴에 "샘플 별 채우기"를 추가했다.

## 05 동작
- 감정 칩: 평온·슬픔·분노·통찰 중 하나를 고른다.
- 제목: 한 줄 이상 입력할 수 있다.
- 본문: 여러 줄 입력, 비어 있으면 안내 문구를 보여준다. 글자 수를 "N자"로 표시한다.
- 임시저장: 입력이 멈추고 0.8초 뒤 UserDefaults에 저장하고 "임시저장됨"을 표시한다. "닫기"를 눌러도 초안이 남아, 다시 열면 이어 쓸 수 있다.
- 본문이 비어 있으면 아래 두 버튼이 흐리게 비활성화된다.
- 조용히 품기: "간직한 별"로 저장하고 홈으로 돌아간다.
- 별 띄우기: 띄운 별로 저장하고 홈으로 돌아간다. 별빛 값은 분석(06)이 없어서 배지에 "—"로 표시한다.

## 검증
- `xcodebuild` 빌드 성공.
- 시뮬레이터에서 확인한 것: 03에서 05 열기 → 칩 선택 → 제목·본문 입력 → 임시저장 표시 → 별 띄우기 → 04에 새 별 표시
- 시뮬레이터 입력 도구가 한글 붙여넣기를 지원하지 않아 영문으로 입력 테스트를 했다. 한글 표시는 안내 문구와 칩으로 확인했다.
